## 빌드 99 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1.2 (99)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터 (판이 `1.1.3` 에서 `1.1.2` 로 **내려간 것**이 맞다)

**준비** — 빌드 97 때 만든 노트(긴 줄이 든 ```` ```swift ```` 상자)를 그대로 쓴다

1. 읽기 → 첫 상자의 **대각선 화살표** → 창 위 오른쪽에 단추가 **둘**: 왼쪽은 **꺾인 화살표**(줄바꿈 켜기), 오른쪽은 **겹친 네모**(복사). 긴 줄은 한 줄 그대로 옆으로 밀린다 (빌드 97 과 같다)
2. **꺾인 화살표** → 긴 줄이 화면 폭에서 **접혀** 여러 줄이 되고, 옆으로는 안 밀린다. 단추는 **좌우 화살표**(줄바꿈 끄기)로 바뀐다
3. 접힌 상태에서 글을 길게 눌러 고른다 → **여러 줄에 걸쳐** 고를 수 있다
4. **닫기** → 다시 **대각선 화살표** → 창이 **접힌 채로** 열린다 (마지막에 고른 것을 기억한다)
5. **좌우 화살표** → 다시 한 줄 그대로 옆으로 밀린다. 닫았다 다시 열어도 그대로
6. 위 오른쪽 **복사** → `복사했습니다` · 체크 표시 → 쓰기 화면에 붙이면 상자 글 그대로 (접힘과 상관없이 원래 줄)

**유튜브 공유 제목 (240)** — 인터넷이 되는 상태에서

7. 유튜브 앱에서 아무 동영상 → **공유** → **느린 여백** → 공유 창의 **주소** 칸 첫 줄이 처음엔 주소였다가 1~2초 안에 **동영상 제목**으로 바뀐다
8. **보내기** → 앱을 연다 → `받은 글` 폴더에 새 노트: 목록의 이름이 **동영상 제목**이고, 열면 첫 줄 `# 동영상 제목` · 아래에 **동영상 제목으로 된 링크** (예전에는 `youtube.com` 같은 사이트 이름 · 주소 링크)
9. 7 을 한 번 더 하되 창이 뜨자마자 **곧바로 보내기** → 잠깐 기다렸다가 닫히고, 노트에는 역시 제목이 들어간다 (보내기가 제목을 기다린다)
10. 사파리에서 공유 → 예전처럼 쪽 제목이 바로 보인다 (바뀐 것 없음)
11. (선택) 비행기 모드에서 7~8 → 제목 없이 예전처럼 주소만 들어간다 — 5초쯤 기다린 뒤 보내진다
