**7 부터 걸림** (2026-10-11 사용자 — *7번부터는 첨부와 같이 로직 점검이 필요해*, 첨부 두 장) — 유튜브 공유 창의 **글** 칸에
`https://youtube.com/watch?v=…&si=…` 가 들어 있고 **주소** 칸이 없다. 보낸 노트는 이름 `https---youtube.com-wat…` · 첫 줄 `# https://…`.

**왜** — 유튜브는 주소를 *주소(URL)* 가 아니라 **글(plain text)** 로 준다. 공유 창은 주소로 온 것만 주소로 알아서(`UTType.url`),
주소가 없으니 제목을 가져오지 않았고(`fetchTitleIfMissing` 의 `url == nil`), 노트는 글의 첫 줄(주소)을 제목으로 썼다.
확인 목록 7 은 *주소 칸* 을 적었는데 **유튜브가 무엇을 주는지는 기기에서만 보인다** — 사파리 길만 알고 적었다.

**경우의 수** (CLAUDE §3.4) — 정답표 `Tools/golden/share-cases.json` 의 `address` 18건:

| 받은 글 | 주소로 온 것 | 어떻게 |
|---|---|---|
| 주소 하나 (앞뒤 빈칸 · 빈 줄 · 대문자 스킴 · 짧은 동영상 · 한글 주소) | 없음 | **주소로 옮기고 글은 비운다** → 제목 가져오기 |
| 주소 하나 | 같은 주소 | 글만 비운다 (주소 줄이 제목이 되지 않게) |
| 주소 하나 | 다른 주소 | 그대로 |
| 글 + 주소 (한 줄 · 두 줄) · 주소 둘 | 없음 | 그대로 — 사용자가 쓴 글의 첫 줄이 제목 |
| `www.…` · `mailto:` · `https://` 뿐 · 사이트 이름 없음 · 주소 가운데 빈칸 | 없음 | 그대로 |
