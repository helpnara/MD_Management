**준비.** 3 ~ 8 은 **아이패드 + 외장 키보드**로, 영상의 그 노트(`- [제목](긴 주소)` 항목이 여럿)로 본다.

0. 설정 → **맨 아래** 회색 글이 `1.1.22 (141)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. **폴더에 들어가기 (296)** — 아무 노트의 쓰기 화면 **···** → **문서 첨부** → 고르기 창에서 `옮겨야 하는 MD파일` 같은 **폴더 안의 폴더**를 누른다 → **들어가진다** (예전에는 골라지기만 했다) → 그 안의 파일(사진 · PDF)을 하나 골라 **열기** → 노트에 링크 한 줄이 들어간다
2. 같은 창에서 폴더를 눌러도 **골라지지 않는다** (파일만 고를 수 있다) → 취소
3. **↓ 한 번씩 (294)** — 그 노트를 쓰기 화면으로 열고 제목 줄에 커서 → ↓ 를 한 번씩 목록 끝까지 → 커서가 **한 줄씩** 내려간다 · 주소가 드러난 항목에서는 ↓ 두 번(주소 줄 → 다음 항목) · 처음이나 끝으로 **튀지 않는다**
4. **↓ 누르고 있기** — 제목 줄로 돌아가 ↓ 를 **꾹 누른 채** 끝까지 → 튀지 않는다 · 끝에서 ↑ 를 꾹 눌러 처음까지 → 튀지 않는다 (빌드 140 에서 튀던 자리)
5. **가로 자리 기억** — 긴 항목의 **가운데쯤**에 커서를 두고 ↓ 로 **빈 줄**을 지나 다음 긴 항목으로 → 커서가 빈 줄에서는 맨 앞, 다음 긴 항목에서는 **원래 가로 자리 근처**로 돌아온다
6. **고르기는 그대로** — 어느 항목에서 ⇧↓ 를 두 번 → 두 줄이 **골라진다** (파랗게) → 아무 데나 눌러 푼다
7. 마지막 항목에서 ↓ → 커서가 **글 끝**으로 (문서 끝을 넘는 것은 원래대로) · 제목 줄에서 ↑ → 글 처음
8. 설정 → 도움 → **진단** → 최근 일에 *쓰기 화면 — 커서 튐:* 으로 시작하는 줄이 **없다** (3 ~ 7 뒤 — 빌드 140 에서는 여기 두 줄이 찍혔다). 있으면 그 줄을 복사해 보내 주세요
9. **다른 첨부 카드 (295)** — 쓰기 화면 **···** → **문서 첨부** → 동영상이나 다른 문서(예: `.docx`) 하나 → 들어온 `[이름](…)` 줄 맨 앞에 `!` → 읽기 화면에 `MOV` · `DOCX` 같은 **종류 글자 + 이름 카드** → 누르면 미리보기
