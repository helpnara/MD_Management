## 빌드 81 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.0.6 (81)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터

**공유 메뉴로 보내기 (213)**

1. 사파리에서 아무 웹 쪽을 열고 **공유** 단추 → 앱 줄에서 **느린 여백** 을 누른다 (줄에 없으면 맨 끝 **더 보기** 에서 찾는다)
   → *느린 여백에 보내기* 창이 뜨고, **주소** 칸에 쪽 제목과 주소가 보인다 → **보내기**
2. 느린 여백을 연다 → 위쪽 알림 띠에 *공유로 받은 글 1개를 받은 글 폴더에 새 노트로 넣었습니다.* → 폴더 목록에 **받은 글** 폴더가 있고,
   그 안에 **쪽 제목 이름의 노트**가 있다. 열면 첫 줄이 그 제목이고 아래에 링크가 있다 — 읽기 모드에서 링크를 누르면 사파리로 열린다
3. 메모 앱에서 글 몇 줄을 골라 **공유** → **느린 여백** → **글** 칸에 고른 글이 보인다. 칸에서 글을 조금 고친 뒤 **보내기**
   → 앱으로 오면 **고친 글**이 든 노트가 생기고, 노트 이름은 글의 첫 줄이다
4. 사진 앱에서 사진 **두 장**을 골라 **공유** → **느린 여백** → *사진 2장* 이 보인다 → **보내기** → 앱으로 오면 `받은 글 2026-…` 이름의 노트가 생기고,
   읽기 모드에서 사진 두 장이 보인다
5. 보내기 창에서 **취소** → 앱을 열어도 새 노트가 생기지 않는다
6. 느린 여백을 켜 둔 채 사파리로 가서 보내고, 앱 바꾸기로 느린 여백에 돌아온다 → 그때 바로 노트가 들어온다 (앱을 껐다 켤 필요가 없다)
7. 같은 쪽을 두 번 보낸다 → 받은 글 폴더에 노트가 둘 생기고 이름이 겹치지 않는다 (뒤엣것은 이름 끝에 2)

**참고 (번호 없이):** 받은 글 노트도 다른 앱(파일 앱)에서 열면 같다 — 파일이 원본이다. 큰 변경 뒤 첫 빌드라 껐다 켜서 그대로인지도 겸사겸사.
