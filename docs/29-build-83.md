## 빌드 83 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.0.7 (83)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. 설정 → 진단 정보 → **최근 일 지우기** 를 누른 뒤, 아무 노트나 쓰기 모드로 열어 **몇 줄 쓰다 멈추다를 2~3분** 되풀이한다 → 커서가 글 끝으로 가지 않는다
2. 1 바로 뒤 최근 일을 본다 → `폴더가 바뀌어 목록을 다시 읽음` 줄이 **쌓여 있지 않다** (전에는 3~4초마다 한 줄). `색인 갱신` 줄은 있어도 된다
3. 같은 최근 일에 `쓰기 화면 — 열린 노트의 글을 갈아 끼움` 줄이 **없다**
4. 노트에 글자 몇 개를 치고 **곧바로** 뒤로 가서 다른 노트를 열었다가 돌아온다 → 마지막에 친 글자까지 그대로 있다
5. (아이패드가 있으면) 아이폰에서 노트를 쓰기 모드로 연 채 손을 놓고, 아이패드에서 **같은 노트**에 한 줄을 더한다 → 아이폰에 몇 초 안에 그 줄이 들어오고,
   커서는 **보던 자리**에 있다 (글 끝으로 안 간다). 최근 일에는 `다른 기기의 변경을 불러옴` 과 `쓰기 화면 — 열린 노트의 글을 갈아 끼움` 이 남는다
6. (아이패드가 있으면) 아이폰은 손을 놓은 채, 아이패드에서 같은 폴더에 **새 노트**를 만든다 → 아이폰 목록에 몇 초 안에 뜬다
