**준비 없음** — 지금 상태 그대로 본다. 설정은 폴더 화면 오른쪽 위 톱니 단추.

0. 설정 → **맨 아래** 회색 작은 글이 `느린 여백 1.1.21 (138)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터 (판이 더는 진단 안에 없다)
1. 설정이 **네 구역** — 폴더 · 노트 · 정리 · 도움 — 이고 구역마다 안내글이 한두 줄. 폴더 안내글의 **이미 마크다운을 모아 둔 폴더** 가 굵게 보이고 별표(`**`)가 안 보인다
2. **폴더** 구역 — 쓰는 곳 · 폴더 이름 · 노트 n개 · **다른 폴더 고르기** · **마크다운으로 내보낸 폴더 가져오기** 다섯 줄 (가져오기가 여기로 왔다)
3. **노트** 구역 — 스위치 셋: 노트를 열 때 읽기 모드로 · 첫 줄을 파일명으로 · 공유할 때 링크된 노트도 넣기. **첫 줄을 파일명으로** 를 켜면 *제목을 따라 파일 이름이 바뀝니다* 창 → **취소** → 스위치가 꺼진 채로 (경고 머리글 구역은 없어졌고 묻는 창이 지킨다)
4. **정리** 구역 — 휴지통 n개 · 안 쓰는 첨부. 둘 다 눌러 들어가진다 (예전 화면 그대로)
5. **도움** 구역 — **사용법** · **진단** 두 줄 (시험 도구 줄 · *시험 도구 보기* 스위치가 없다)
6. **사용법** → 주제 아홉: `파일` 앱에서 열기(세 단계) · 노트 잇기 · 읽기 모드 · 줄바꿈 고치기 · 마크다운으로 내보낸 폴더 가져오기 · 노트 옮기기 · 휴지통 · 안 쓰는 첨부 · 다른 폴더 고르기 · 첫 줄을 파일명으로. 글 속 굵은 글 · `코드 글씨` 가 그려진다 (별표 · 백틱이 안 보인다)
7. **진단** → 구역이 **상태** (iCloud 를 잡았나 · 하위 폴더 · 금고 파일 · 색인된 노트 · 제목만 색인 · 색인 크기 · 색인 다시 만들기) · 최근 일 · (마지막 붙여넣기) · **진단 정보 복사** 뿐. 판 · 번들 ID · 경로 · trigram · 마지막 갱신 · 목록 읽기 · 시험 도구 줄이 **없다**
8. 진단 → **진단 정보 복사** → 아무 새 노트에 붙여넣기 → 글에 `판:` · `번들:` · `경로:` · `trigram` · `마지막 갱신` 이 **있다** (화면에서 뺀 값도 복사 글에는 다 담긴다). 붙여넣은 노트는 지운다
9. 설정 맨 아래 **판을 다섯 번 빠르게** 누른다 → 판 아래 *시험 도구를 보이고 있습니다 — 다섯 번 더 누르면 감춥니다* · 도움 구역에 **시험 도구** 줄이 생긴다 → 들어가면 맨 위에 **걸린 시간 · 경로** 구역(마지막 갱신 · 목록 읽기 · 마지막 검색 · trigram · 경로)과 그 아래 첨부 시험 · 큰 노트 · 띠 · 규모 시험
10. 설정을 닫았다 다시 열어도 시험 도구 줄이 **그대로** (기억한다) → 판을 다시 **다섯 번** → 줄과 안내가 사라진다
