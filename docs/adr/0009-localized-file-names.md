# ADR-0009 — 영문판에서 앱이 짓는 파일 · 폴더 이름: 기기 언어로 짓되 이미 있는 쪽을 먼저 찾는다

**상태** 정함 (2026-10-07 사용자 — *2번은 추천안*) · 구현 전 (219 · 1.1)

## 맥락

영문판(219)을 만든다. 앱은 몇 군데서 **스스로 이름을 지어 파일 · 폴더를 만든다** — 그 이름은 화면 글자가 아니라 **사용자 iCloud 폴더에 남는다** (ADR-0001, 파일이 원본).

| 자리 | 지금 (한국어) | 코드 |
|---|---|---|
| 새 노트 | `새 노트.md` · 첫 줄 `# 새 노트` | `LibraryModel.createNote` |
| 공유로 받은 글의 폴더 | `받은 글/` | Core `IncomingShare.folder` |
| 제목 없는 공유 | `받은 글 2026-10-07 09-30.md` | `LibraryModel.importShared` |
| 충돌 사본 | `이름 (충돌 2026-10-07 09.30).md` | `FolderStore.conflictName` |
| 이름을 비운 새 폴더 · 이름 없는 노트 | `새 폴더` · `노트` | `Paths.safeFileName(fallback:)` |

한 사람이 **한국어 아이폰과 영어 아이패드**를 같은 iCloud 로 쓰면, 기기 언어로만 지을 때 공유로 받은 글이 `받은 글/` 과 `Inbox/` **두 폴더로 갈린다.**

## 결정

**기기 언어로 짓는다. 다만 *모으는 폴더*(받은 글)는 이미 있는 쪽을 먼저 찾는다** — `받은 글/` 이 있으면 영어 기기도 그리로, `Inbox/` 가 있으면 한국어 기기도 그리로.
둘 다 있으면 노트가 더 많은 쪽 (같으면 기기 언어 쪽). 한 번 정한 폴더를 기억하지 않는다 — 기억은 앱 DB 가 된다 (ADR-0001). 폴더 목록이 곧 기억이다.

- 새 노트 · 충돌 사본 · 제목 없는 공유 · 빈 이름 폴더는 **한 번 만들고 끝**인 이름이라 기기 언어 그대로 (갈려도 모을 것이 없다).
- 충돌 사본을 **알아보는** 쪽(목록 · 정리)은 두 말(`충돌` · `conflict`)을 다 알아본다 — 짓는 말과 읽는 말이 갈리면 안 된다.
- 이미 있는 파일 이름은 **절대 바꾸지 않는다** (앱은 사용자 파일 이름을 손대지 않는다 — 제목 따라가기(89)만 예외).

## 대가

- 한 iCloud 에 두 언어 기기가 섞이면 새 노트 이름이 `새 노트` · `Untitled` 로 섞일 수 있다 — 첫 줄을 고치면 이름이 따라가므로(89) 오래 남지 않는다.
- *이미 있는 쪽 찾기* 는 Core 함수 하나 + 파이썬 쌍둥이 정답표로 지킨다 (구현 때).
