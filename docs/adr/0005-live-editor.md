# ADR-0005 — 라이브 편집: 커서가 있는 줄만 원문, 나머지는 렌더

**상태** 확정 (2026-09-13)

## 결정

**단일 `UITextView`(TextKit 2) 안에서 원문은 항상 그대로 두고, 커서가 없는 문단은
렌더링된 모습으로 · 커서가 있는 문단은 마크다운 원문으로 보인다.**

**원리 한 줄.** 파일의 문자열이 곧 `textStorage.string` 이다. 어떤 글자도 지우거나
바꿔 넣지 않는다. 보이는 모습의 차이는 전부 **속성**(글꼴 · 색 · 마커 숨김 · 이미지
프래그먼트)으로 낸다. 그래서 저장은 `textStorage.string` 을 그대로 쓰면 끝이고,
**매핑 버그가 생길 자리가 없다.**

## 세 단계 — 각 단계가 그 자체로 쓸 만한 편집기

| 단계 | 커서 없는 문단 | 커서 있는 문단 | 만드는 것 |
|---|---|---|---|
| **L1 스타일** | 제목 크게 · 굵게 / 기울임 · 인라인 코드 고정폭 · 인용 회색 세로선 · 목록 들여쓰기. 마커(`#` `**` `-`)는 남되 흐리게 | 같은 스타일 + 마커 진하게 | `LineStyler`(Core) + `NSTextStorage` 서브클래스 |
| **L2 마커 숨김** | 마커를 숨긴다 (0.01pt · 투명 · 자간 0). 문자열엔 그대로 있어 선택 · 복사 · 저장은 원문 | 마커가 나타난다 | `textViewDidChangeSelection` → 이전 문단 · 새 문단 두 개만 다시 속성 |
| **L3 블록 렌더** | `![](assets/a.jpg)` 줄 아래에 사진 · 체크박스 `[ ]` 를 탭 가능한 기호로 · 수평선 · 링크 밑줄 | 원문 | TextKit 2 `NSTextLayoutFragment` 서브클래스 |

표 · 코드 블록 · 수식은 1.0 라이브에서 **고정폭 원문 그대로**. 완전한 표 렌더는
상단 "읽기" 토글(WKWebView, ADR-0004)이 맡는다.

## 여기서 버그가 난다 — 규칙

- **한글 조합 중에는 속성을 건드리지 않는다.** `textView.markedTextRange != nil` 이면
  재스타일을 미룬다. 조합 중 속성 갱신은 조합을 끊는다 (자음 · 모음이 따로 찍힘). → S10
- **재스타일은 문단 단위 · 증분.** 편집된 문단 + 커서가 떠난 문단 + 커서가 온 문단만.
  전체 재스타일은 파일을 열 때 한 번. → S11
- **`NSTextStorage.processEditing` 안에서만 속성을 바꾼다.** 밖에서 바꾸면 되돌리기
  스택이 속성 변경까지 기록해 `⌘Z` 가 이상해진다. 속성 변경은 undo 에 넣지 않는다.
- **커서 줄 판정은 "커서가 속한 문단"**(`\n` 기준). 문단이 여러 화면 줄로 접혀도 그
  문단 전체가 원문이다.
- **탭 → 커서 줄 전환 시 텍스트가 재배치**된다 (마커가 나타나 줄이 길어짐).
  스크롤 위치를 문단 기준으로 고정해 화면이 튀지 않게 한다. **빌드 첫 확인 항목.**
- **이미지 프래그먼트는 미리 디코딩해 캐시**(긴 변 화면 폭 2×). 스크롤 중 디코딩 금지.
- **글꼴은 `UIFontMetrics` 로 스케일.** Dynamic Type 이 바뀌면 전체 재스타일 한 번.
- 하드웨어 키보드 `⌘/` 로 "전체 원문 보기" 토글 — 디버깅 · 대량 편집용.
- **접근성:** 0.01pt 로 숨긴 마커를 VoiceOver 가 그대로 읽는다. `accessibilityAttributedLabel`
  로 가리거나, 안 되면 VoiceOver 실행 중에는 L1 로 내려간다. → A10

## 버린 대안

| 대안 | 버린 이유 |
|---|---|
| CodeMirror 6 in `WKWebView` (옵시디언 방식) | iOS `contenteditable` 의 **한글 조합(IME) 깨짐 · 커서 튐 · 키보드 닫힘**을 맥 없이 원격에서 잡을 수 없다 |
| 블록 편집기 (블록마다 뷰, 탭하면 원문) | 블록 간 선택 · 커서 이동 · 병합을 다시 만들어야 하고, `LazyVStack` 포커스 함정을 지난 앱에서 두 번 밟았다 |
| 원문 ↔ 렌더 두 문자열을 매핑하는 WYSIWYG | **매핑 버그가 곧 자료 손상이다.** 이 앱에서 가장 피하고 싶은 것 |

## 물러설 길

- L2 가 실기기에서 흔들리면(커서 튐 · 선택 어긋남) **L1 로 물러서 출시한다.** 마커가
  흐리게 남아 있어도 "제목이 크고 굵은 글이 굵은" 편집기는 이미 쓸 만하다.
- L3 이미지 프래그먼트가 흔들리면 이미지 줄 아래에 **작은 썸네일 버튼**(탭하면 전체화면)으로
  물러선다.
- **두 후퇴 모두 파일 · 저장 경로에 손대지 않으므로 자료 위험이 없다.**

## 값의 출입구

**본문을 고치는 길은 편집기 하나뿐이다.** v0.4 초안에 있던 "뷰어의 체크박스 토글"
예외는 없앤다 — L3 가 라이브 편집기 안에서 `[ ]`↔`[x]` 한 글자 바꾸기로 흡수한다.
읽기 모드(WKWebView)는 **완전한 읽기 전용**이다.
