# ADR-0006 — 아이폰 · 아이패드는 유니버설 앱 하나

**상태** 확정 (2026-09-13, 사용자 확인)

## 결정

**번들 ID 하나 · 스토어 등록 하나 · 코드베이스 하나.** 아이패드 전용 화면 구성은
같은 코드베이스 안에서 `horizontalSizeClass == .regular` 분기와 별도 `Views/iPad/`
뷰로 만든다.

- `NavigationSplitView` 3단: 폴더 사이드바 · 파일 목록 · 뷰어/편집기.
  아이폰에서는 같은 뷰가 스택으로 접힌다.
- 편집기 ↔ 미리보기 **나란히** (가로 · regular 폭). 아이폰은 토글.
- 하드웨어 키보드: `⌘N` 새 노트 · `⌘F` 찾기 · `⌘E` 편집/미리보기 · `⌘S` 즉시 저장 ·
  `⌘B`/`⌘I` 강조. **키보드 위 띠는 하드웨어 키보드 연결 시 숨긴다.**
- 사진 · 파일을 **드래그해서 편집기에 놓기**(`.dropDestination`) — 아이패드에서 첨부의 정문.
- Stage Manager · 창 크기 변경은 `ViewThatFits` 로 견딘다. **폭을 숫자로 못 박지 않는다.**
- CI 스크린샷에 **iPad 3단 · 아이폰 스택 · 큰 글씨** 세 장이 첫 주부터.

**1.0 에 아이패드 화면 구성을 같이 만든다.** "깨지지 않는다" 가 아니라 "아이패드답다"
가 기준이다.

## 버린 대안

**앱 두 개(번들 ID 둘).** 심사 · 스크린샷 · 방침 · TestFlight 그룹이 전부 두 배가
되는데, 자료 폴더는 어차피 같으므로 얻는 것이 없다. 아이패드는 "다른 앱" 이 아니라
**"같은 자료를 넓은 화면으로"** 다.

## 미확인

- **A8** — 아이패드 시뮬레이터 스크린샷에서 3단 분할이 실제로 펼쳐지는가 (가로 · Pro 13"). 1주차 CI.
