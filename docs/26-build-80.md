## 빌드 80 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.0.6 (80)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터

1. 노트 **가** 를 하나 만들고, 다른 노트 **나** 에서 편집 도구의 **노트 연결**로 **가** 를 연결한다 → **가** 를 읽기 모드로 열면 맨 아래에 가는 선 밑으로 *이 노트를 가리키는 노트 · 1* 과 **나** 가 보인다
2. 1 의 **나** 를 누른다 → **나** 가 열린다 (쓰기 모드). 왼쪽 위 `<` 로 돌아오면 **가** 의 읽기 모드다
3. 다른 폴더의 노트 **다** 에서도 **가** 를 연결한다 → **가** 를 읽기 모드로 다시 열면 *· 2* 이고, **다** 옆에 흐린 글씨로 그 폴더 이름이 붙는다
4. **나** 에서 **가** 를 가리키는 링크를 지운 뒤 **가** 로 와서 읽기 모드로 → 목록에서 **나** 가 빠져 있다
5. 아무 노트도 가리키지 않는 노트를 읽기 모드로 → 맨 아래에 선 · 칸이 **없다**
6. **나** 안에 **가** 를 두 번 연결한다 → **가** 의 목록에 **나** 는 한 번만 보인다

**참고 (번호 없이):** 목록은 화면에만 있다 — **가** 의 파일을 다른 앱에서 열어도 아무것도 붙어 있지 않다. 처음 열 때 목록이 한 박자 늦게 붙을 수 있다 (폴더의 노트를 다 읽어 센다).
