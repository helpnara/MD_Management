## 빌드 95 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1.2 (95)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터

**붙여넣기 알림 (236)** — 준비: 웹 페이지나 메모에서 **굵은 글씨 · 목록이 섞인 글**을 몇 줄 복사해 둔다

1. 노트를 쓰기 모드로 열고 복사한 글을 붙여 넣는다 → 키보드 바로 위(도구 띠 아래)에 **옅은 파란 띠**가 뜬다 — 왼쪽에 파란 **i**, 글은 `서식을 마크다운으로 바꿨습니다. 되돌리기로 무를 수 있습니다.` (예전에는 붉은 띠 · 느낌표)
2. 아무것도 누르지 않고 **5초쯤** 기다린다 → 띠가 저절로 사라진다
3. 한 번 더 붙여 넣고, 띠가 떠 있고 **키보드도 떠 있는 채로** 왼쪽 위 **‹** 로 목록에 돌아온다 → 띠는 사라져 있고, 노트 목록이 **화면 아래까지** 다 보인다 (예전에는 중간에서 잘렸다)
4. 웹 주소 하나(`https://…`)만 복사해 붙여 넣는다 → 옅은 파란 띠 `주소를 링크로 만들었습니다. 되돌리기로 무를 수 있습니다.` → 띠 오른쪽 **×** 를 누르면 바로 닫힌다
5. 1 처럼 붙여 넣은 뒤 띠가 떠 있는 동안 **흔들어서 실행 취소**(또는 세 손가락으로 왼쪽 쓸기) → 붙여 넣은 글이 통째로 빠지고 **붙이기 전으로** 돌아간다 (되돌리기는 예전 그대로 — 바꾼 글을 한 번에 넣으므로 한 번에 빠진다)

**공유로 받은 글 (236)**

6. 사파리에서 아무 쪽이나 열고 **공유 → 느린 여백** 으로 보낸 뒤 앱을 연다 → 옅은 파란 띠 `공유로 받은 글 1개를 받은 글 폴더에 새 노트로 넣었습니다.` 가 뜨고 5초쯤 뒤 사라진다. `받은 글` 폴더에 새 노트가 있다
