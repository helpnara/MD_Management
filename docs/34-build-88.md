> 2026-10-07 사용자 — *1.0.8은 더 기능이 개선되면 올리고 219 착수하자.* · *영어 전문가 또는 외국인의 관점에서 한글-영어 번역을 검토해주고, 앱에 반영하면 될 것 같아.*

**아직 아닌 것 (2단계 이후).** 앱이 짓는 파일 · 폴더 이름(`새 노트` · `받은 글` · `(충돌 …)`)은 영어 기기에서도 한국어다 — ADR-0009 로 2단계에서.
영어 견본 노트 · 영어 스크린샷 · 스토어 · 처리방침도 뒤 단계. 그래서 **이 판은 아직 심사에 내지 않는다.**

## 빌드 88 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1 (88)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터

**한국어는 그대로인가 (가장 중요)**

1. 폴더 화면 · 노트 목록 · 쓰기 · 읽기 · 설정 · 휴지통 · 진단 화면을 한 번씩 연다 → 글자가 전과 같은 한국어다 (영어나 `%lld` 같은 기호가 보이지 않는다)
2. 노트 목록 화면의 폴더+ 단추 → 창에 *<폴더> 안에 폴더를 만듭니다. 같은 이름이 있으면 뒤에 번호를 붙입니다.* (취소)
3. 노트 목록 제목 아래 *노트 N개* 가 맞는 숫자로 보인다

**영어로 바꿔 보기** — 아이폰 **설정** 앱 → 아래로 내려 **느린 여백** → **언어(Preferred Language)** → **English** (기기 전체는 그대로)

4. 느린 여백을 다시 연다 → 폴더 화면 · 노트 목록 · 설정의 글자가 영어다 (*Settings* · *Trash* · *New Note* · *Pinned Notes* …)
5. 노트 목록 제목 아래가 노트 하나면 *1 note*, 여럿이면 *3 notes* 처럼 나온다
6. 폴더+ 단추 → 창에 *Creates a folder in …* 처럼 영어
7. 쓰기 화면 아래 도구 띠의 단추를 **길게 누르면** *Bold* · *Increase Indent* 같은 영어 이름이 뜬다. 목록 모양 단추를 길게 누르면 *Bulleted List* · *Numbered List* · *Checklist* · *Remove List*
8. 영어로 남지 않는 곳이 있으면 화면을 캡처해 주세요 — 단 **최근 일 기록 · 시험 도구 안의 글 · 새 노트 이름(`새 노트`)** 은 아직 한국어가 맞다 (2단계)
9. 다 보면 같은 자리에서 언어를 **한국어**로 되돌린다

**참고 (번호 없이):** 큰 변경 뒤 첫 빌드라 — 껐다 켜서 그대로인가 · 다른 앱에서 열어도 같은가.

## 결과 (2026-10-07 사용자)

**1~6 · 9 확인 완료.** 한국어 화면 그대로 · 이 앱만 English 로 바꾸면 영어 · *1 note / 3 notes* · 새 폴더 창 영어 · 한국어로 되돌림.

**7 — 목록 모양 단추만 됨. 내 확인 목록이 틀렸다.** 도구 띠의 일반 단추는 **길게 눌러도 이름이 뜨지 않는다** — 이름(`accessibilityLabel`)은 보이스오버만 읽는다.
길게 누르면 메뉴가 뜨는 것은 목록 모양 단추(`Menu`) 하나뿐. 코드 주석이 *길게 누르기가 읽는다* 고 잘못 적혀 있었고 나는 코드 대신 주석을 믿었다 —
CLAUDE.md §3-2 *새 동작을 적기 전에 그 자리의 코드를 한 번 읽는다* 를 또 어겼다 (주석도 바로잡음). 영문판 문제가 아니다. 길게 눌러 이름을 띄우고 싶으면 새 기능으로 연다.

**8 — 로그만 한국어: 의도한 대로.** 최근 일 기록 · 시험 도구 안 글 · 진단 보고는 개발용이라 ① 에서 한국어로 두었다 (08-feedback 219 ① 착수 절).
영어 사용자도 진단 화면에서 볼 수 있다 — 영어로 바꿀지는 뒤에 정한다.
