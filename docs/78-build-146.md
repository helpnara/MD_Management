## 빌드 146 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → **맨 아래** 회색 글이 `1.1.23 (146)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. **자판을 올린 채로** — 아무 노트의 쓰기 화면에서 글 한가운데를 눌러 **자판을 올린다** → `···` → **문서 첨부** → 자판이 내려가고 고르기 창이 뜬다 → 창 **맨 아래 띠(최근 항목 · 둘러보기)** 가 보인다
2. 그 창에서 **위 폴더로 나오기** — 왼쪽 위 뒤로 단추로 한 단계 위 폴더로 → 또 위로 → **둘러보기** 를 눌러 다른 위치(나의 iPhone · iCloud Drive 등)로 옮겨 간다 → 다른 폴더 안의 파일 하나(PDF · 사진)를 골라 **열기**
3. 노트로 돌아오면 **1 에서 커서가 있던 자리**에 링크 한 줄이 들어와 있다 (자판은 내려가 있다 — 다시 쓰려면 글을 누른다)
4. 같은 방법으로 자판을 올린 채 `···` → **사진첩에서** → 자판이 내려가고 사진 고르기 창이 아래까지 보인다 → 사진 하나 → 커서 자리에 들어온다
5. 자판을 올린 채 `···` → **이미 있는 파일 연결** → 자판이 내려가고 고르는 창이 뜬다 → 하나 고르면 커서 자리에 링크
6. (아이패드가 있으면) 화면 자판을 올린 채 위 도구 줄의 넣기 단추 → **문서 첨부** → 1 · 2 와 같이 창 아래까지 보이고 다른 폴더로 옮겨 간다
