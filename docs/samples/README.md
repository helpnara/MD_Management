# 견본 노트 — 스토어 스크린샷용

**실제 쓰시는 노트로 찍지 않으려고 둔 것들이다** (2026-09-24). 스크린샷은 스토어에
영구히 공개되고, 앞서 찍은 것에 **다른 앱 이름 · 회사 맥락 · 사생활**이 들어 있었다.

## 넣는 법

1. 설정 → **다른 폴더 고르기** 로 빈 폴더를 하나 만들어 고른다
   (또는 `파일` 앱에서 새 폴더를 만들고 그것을 고른다)
2. 이 폴더의 `.md` 다섯 개를 그 안에 넣는다
3. **사진은 앱으로 넣는다** — `제주 여행` 을 열고 `…` → **사진첩에서**.
   그래야 `assets/` 에 들어가고 본문 링크가 저절로 맞는다
4. `주간 계획` 을 **고정**해 둔다 (목록을 밀어 `고정`) — 목록 사진이 풍성해진다
5. 다 찍은 뒤 설정 → **기본 iCloud 폴더로 돌아가기**.
   **파일은 안 지워진다** — 앱이 보는 곳만 바뀐다

## 어느 노트로 무엇을 찍나

| 사진 | 노트 | 왜 |
|---|---|---|
| **1 · 편집 모드** | `주간 계획` | 표가 없다. 커서를 **`쌓아 둔 것을 덜어내는 주`** 줄에 두면 그 줄만 `**…**` 로 보이고 위아래는 읽는 모습이라 **대비가 한눈에** 보인다 |
| **2 · `파일` 앱** | — | 폴더를 열어 `.md` 다섯이 보이게. 아래 **iCloud에 동기화됨** 이 보이면 더 좋다 |
| **3 · 읽기 모드** | `제주 여행` | 제목 · 사진 · 표 · 목록이 **한 화면에** 들어간다 |
| 4 · 노트 목록 | — | 고정된 노트 구역과 다섯 줄 |
| 5 · `>>` 목록 | `회의록` | 아무 데나 `>>주간` 을 치면 목록이 뜬다 |
| 6 · 찾기 | — | `제주` 나 `정리` 로 찾으면 여러 노트가 걸린다 |

## 왜 이 내용인가

- **남의 상표가 없다** (`CLAUDE.md` §6)
- 회사 · 팀 · 사람 이름이 없다
- `주간 계획` · `회의록` 의 **겹친 목록은 빈칸 셋**이다 — 앱의 탭이 만드는 것과 같다
- `주간 계획` 의 `문제정의-근거수집-대안비교-권고…` 줄은 **한 줄을 넘는다** —
  접힌 줄이 글에 맞는 것이 보인다 (155)
- 노트끼리 링크가 걸려 있다 (`주간 계획` ↔ `회의록`)
- 표는 **세 칸**이라 아이폰에서 안 잘린다
