# 로드맵 — 지금 어디까지 왔나

> **세션을 시작하면 이 문서를 가장 먼저 읽는다.** 아래 두 표가 이 프로젝트의 기억이다.

**지금 어디까지:** 1주차가 섰다. **TestFlight 빌드 6** 까지 올렸고 `Files` 앱에
`느린 여백` 폴더가 보인다 (**A2 확인**). 읽기 모드(ADR-0004)가 아이폰 · 아이패드
양쪽에서 렌더된다 — 제목 · 목록 · 표 · 코드 · 체크박스 · 사진.

**확인된 가정:** A1(이름) · A2(iCloud 폴더) · **A3(첨부 렌더)** · A7(리눅스 빌드) ·
A8(아이패드 3단) · A9(API 키) · **A13(한글 이름)**. **1주차 가정이 다 닫혔다.**
안정화 기준 S5 · S13 도 찼다.

**2주차 착수:** **라이브 편집기 L1 + 자동 저장** 을 만들었다 (빌드 7 대기).
`LineStyler`(Core, 순수 함수) → `MarkdownTextStorage`(속성만 바꾼다) →
`UITextView`(TextKit 2). 기댓값은 `markdown-it-py` 가 따로 계산한 44건과 견준다.

**빌드 7 (TestFlight)** 에 L1 편집기 · 자동 저장 · `파일` 앱에서 열기 · 설정 화면이
들어갔다. 시뮬레이터 스크린샷에서 제목 · 마커 · 링크 · 목록이 그려지는 것을 봤다.

**오늘 세운 심판 하나 더:** `Tools/ci/not-blank.py` — 스크린샷의 **내용 칸 화소**를
센다. 파일 크기 가드가 하루에 세 번 틀렸다 (놓침 · 헛짚음 · 놓침). 빈 편집기가
114KB 로 통과한 것을 이것이 잡는다.

**빌드 7 실기기: S10(한글 조합) · S2(껐다 켜서 그대로) 확인.** 파일 앱에서 열기도 됐다.

**빌드 8 · 9:** 새 노트 · 이름 바꾸기 · 지우기(`.trash/`) · 휴지통 · 목록 줄바꿈 ·
매달린 들여쓰기 · 머리말 흐리기. **A14 확인.** 실기기가 잡은 것: 확인 창이 닫히며
대상을 먼저 지우는 순서 버그 · 폴더 화면에서 못 돌아오는 선택 고착.

**빌드 10:** 폴더 화면 복귀 확인. **빌드 11 (진행 중):** 머리말 흐리기 안정화(증분 재칠의
문맥 함정) · **사진 넣기**(사진첩 → `assets/` JPEG → 커서 자리 링크).

**다음 할 일:** 빌드 11 판정 → 카메라 · L2(마커 숨김) · 충돌 · (b) 폴더 고르기 UI.

**오늘 세운 심판 둘** (둘 다 A2 를 쫓다 나왔다):

- 앱 안 **진단 화면** — 폴더 종류 · iCloud 를 잡았나 · 경로 · 파일 수 · 복사 버튼.
  3주차 예정이었는데 이것이 없어서 원인을 추측으로 좁혔다. 앞당겼다.
- CI 의 **번들 검사** — `project.yml` 에 쓴 `NSUbiquitousContainers` 가 정말
  번들에 들어갔는지. 설정 파일과 결과물은 다른 것이다.

## 1. "1.0" 이 무엇인가

**1.0 (TestFlight, 나 혼자 · 내 기기들)** — 한 사람이 자기 폴더 안의 `.md` 파일을
아이폰 · 아이패드에서 **보고 · 고치고 · 찾는다.** 이미지 · 첨부는 마크다운 표준
링크로 그 자리에서 본다.

**2.0 (App Store 공개)** — 태그 · 백링크 · `[[wikilink]]` 이동 · 앱 잠금 · 위젯 ·
공유 확장 · PDF 내보내기. 1.0 에 넣지 않는다.

**만들지 않는 것 (1.0 · 2.0 공통)** — 다른 Apple ID 와 공유 · 외부 네트워크 · 계정 ·
서버 · 자체 파일 형식.

## 4. 앱 이름 — `느린 여백` (2026-09-13 확정)

`느린 부자의 기록` 과 한 가족 브랜드로 묶었다. 단독 `여백` 은 KIPRIS 에서 등록
상표가 확인돼 쓰지 않는다.

**이름은 코드의 두 곳에만 있다.** 바뀌면 이 두 줄과 문서를 고치면 된다:

| 자리 | 파일 | 값 |
|---|---|---|
| 스토어 · 홈 화면 이름 | `project.yml` → `CFBundleDisplayName` | `느린 여백` |
| `Files` 앱의 폴더 이름 | `project.yml` → `NSUbiquitousContainerName` | `느린 여백` |

**Xcode 타깃 · 스킴 이름(`Notebook`)과 번들 ID(`com.helpnara.markdown`)는 이름과
무관하게 고정**이다. 번들 ID 는 App Store 등록 후 바꿀 수 없으므로 일부러 이름을
안 넣었다.

**아이콘**은 `Tools/icon/icon-source.png` 를 `Tools/icon/bake-icon.py` 가 굽는다.
원본을 저장소에 두는 이유는 결과물만 있으면 나중에 손볼 수 없기 때문이다.

## 5. 일정 (목표이지 마감이 아니다 — 판정은 §2 표가 한다)

| 주 | 목표 | 끝나는 조건 |
|---|---|---|
| **1주 뼈대** | 저장소 · CI 4개 · DesignSystem · `NavigationSplitView` 뼈대 · 폴더 열기 (a)(b) · 목록 · 뷰어(이미지 포함) · 방침 페이지 · TestFlight 1빌드 | 실기기에서 내 iCloud 폴더의 노트를 사진과 함께 읽는다 (S1 · S5 절반 · A2 · A3 · A13) |
| **2주 편집 · 첨부** | 라이브 편집기 L1→L2 · 자동 저장 · 충돌 처리 · 사진 넣기 · 삭제 / 이름 바꾸기 | S2 · S3 · S4 · S5 · S10 |
| **3주 검색 · 공유 · 안정화** | 라이브 L3 · FTS5 색인 · 검색 화면 · 태그 · 공유(.md/zip) · 진단 · 큰 글씨 정리 · 아이패드 마무리 | S6 · S7 · S9 · S11 · S12 · S13 |
| +2주 | S8 (크래시 0건 2주) 관찰. 그동안 스토어 준비 | 안정화 표에 날짜가 다 찬다 |

**일정에 안 잡혀 있던 것 (v0.5 에서 추가):**

- TestFlight **첫 빌드는 베타 심사에 1~2일**이 걸린다. 1주차에 미리 한 번 올려 둔다.
- CI 한 바퀴가 **10~15분**이다. 하루에 돌릴 수 있는 왕복 수가 정해져 있다.
- L2 가 실기기에서 흔들리면 **L1 로 물러서 출시**한다 (ADR-0005 §후퇴). 일정을 늘리지 않는다.
