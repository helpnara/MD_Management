## 빌드 115 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1.12 (115)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터

**아이폰 — 폴더 화면의 찾기 칸**

1. 노트 목록에서 왼쪽 위 뒤로 → 폴더 화면 **맨 위에 `모든 노트에서 찾기` 칸**이 당기지 않아도 늘 보인다
2. 그 칸을 누르고 **아무것도 치지 않는다** → 폴더 목록 대신 **최근 고친 노트** — 가장 최근이 맨 위 · 10개까지. 줄마다 제목 · 고친 날짜와 시각 · (맨 위 폴더가 아닌 노트는) 폴더 이름. 맨 아래 *제목과 본문을 찾습니다. tag:태그 · path:폴더 로 좁힐 수 있습니다.*
3. 칸 오른쪽 **X** → 폴더 목록으로 돌아온다
4. 2 에서 최근 노트 하나를 누른다 → 그 노트가 열린다 (노트 목록이 잠깐 지나가도 맞다). 뒤로 → 노트 목록 (전에 보던 폴더) → 뒤로 → 폴더 화면에 **폴더 목록**
5. 그 노트에 글자 하나를 치고 2초 기다린 뒤 뒤로 두 번 → 찾기 칸을 누르면 **그 노트가 맨 위** · 시각이 방금
6. 폴더 화면 찾기 칸에 **다른 폴더에만 있는 낱말**을 친다 → 결과에 그 노트 · 줄 아래 폴더 이름 → 누르면 노트가 열린다 (4 처럼). 뒤로 → 노트 목록에도 같은 결과 → 뒤로 → 폴더 화면에도 같은 결과 → **X** 를 누르면 폴더 목록
7. 없는 말을 친다 → *결과 없음* 안내
8. 노트 목록 화면에서 목록을 아래로 당겨 나오는 찾기 칸의 안내 글이 **`모든 노트에서 찾기`** — 거기서 찾아도 6 과 결과가 같다

**아이패드** (있으면)

9. 왼쪽 폴더 칸 맨 위에 찾기 칸 · **가운데 노트 목록에는 찾기 칸이 없다**. 왼쪽에서 찾으면 결과가 왼쪽에 · 누르면 오른쪽에 열린다 · 가운데는 고른 폴더의 노트 그대로
10. (외부 키보드) `⌘F` → 왼쪽 칸이 보이며 찾기 칸이 열린다

**공유 창** (같은 값을 쓰게 바꿨다)

11. 다른 앱에서 글 → 공유 → 느린 여백 → 넣을 곳 목록의 **최근 고친 노트** 다섯이 예전처럼 보인다 (고정한 노트를 뺀 2 의 위쪽 차례)

**4 · 6 이 노트를 열지 않고 목록에 멈추면** — 아이폰에서 두 칸을 한 번에 넘어가는 길이 막힌 것이다. 그대로 알려 주세요 (화면 찍기 16 이 같은 것을 본다).
