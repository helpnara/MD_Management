> 이 부분은 반드시 수정이 되어야 해. 메모에서 사용한 양식을 최대한 MD 문법으로 잘 변환될 수 있게.* 이어서 *중간에 이미지가 있다면
> 이미지도 함께 파일로 저장하고 링크로 변환하는 부분까지.* 200 · 201 은 *다음 이슈가 나오면 같이* 로 정해 둔 것이다.
> 1.0.4 (빌드 73) 가 심사 중이라 판은 **1.0.5**.

진단 화면에 **마지막 붙여넣기** 칸을 더했다 — 붙여넣기가 이상하게 바뀌면 *붙여넣은 서식 복사* 로 클립보드의 실제 모습을 보내 줄 수 있다.
메모 앱이 무엇을 싣는지 이 세션에서는 볼 수 없어서 (CLAUDE.md §2) 실기기에서 받아 볼 길을 둔다. 앱을 끄면 사라지고, 단추를 눌러야만 나간다.

## 빌드 74 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

**메모에서 붙여넣기 (206)**

1. 메모 앱에서 **제목 · 머리말 · 본문 몇 줄 · 굵은 글 · 글머리 목록 · 번호 목록 · 표 · 표 뒤의 글**이 든 메모를 통째로 복사해 이 앱의 노트에 붙인다 → **표 뒤의 글까지 모두** 들어오고, 알림 띠에 *서식을 마크다운으로 바꿨습니다* 가 뜬다. 제목은 `#`, 머리말은 `##`, 목록은 `- ` · `1. `, 굵은 글은 `**…**`, 표는 `| … |` 줄로 들어온다
2. 붙인 직후 **되돌리기**(흔들기 또는 키보드의 되돌리기) 한 번 → 붙이기 전으로 돌아간다
3. 1 의 노트를 **읽기 모드**로 → 제목 · 목록 · 표가 그려진다. 메모의 표는 첫 줄이 머리줄이 아니라서 **맨 위에 빈 머리줄**이 하나 있다
4. 메모의 **체크리스트**를 복사해 붙인다 → `- [ ]` · `- [x]` 로 들어오는지 봐 주세요. *메모가 체크 표시를 클립보드에 어떻게 싣는지 몰라* 안 될 수 있습니다 — 그러면 5번처럼 보내 주세요
5. 어떤 붙여넣기든 이상하게 바뀌면: 설정 → 진단 정보 → **마지막 붙여넣기** → **붙여넣은 서식 복사** → 여기 대화에 붙여 주세요 (붙인 글이 그대로 담깁니다)
6. 메모의 **고정폭** 문단 여러 줄을 붙인다 → ```` ``` ```` 로 감싼 코드 덩어리로 들어온다

**붙여넣은 사진 (207)**

7. 메모에서 **글 사이에 사진이 든** 부분을 복사해 붙인다 → 사진 자리에 `![](assets/2026-10-…-1.jpg)` 같은 줄이 들어오고, 읽기 모드에서 사진이 보인다. 파일 앱의 그 폴더 `assets` 에 사진 파일이 있다. *메모가 사진을 클립보드에 싣는 방식을 여기서 못 봐서* 사진이 빠지고 글만 들어올 수 있습니다 — 그러면 5번처럼 보내 주세요

**다른 곳에서 붙여넣기 (206 · 157)**

8. 클로드 같은 AI 답(제목 · 표 · 목록이 섞인 답)을 복사해 붙인다 → 표만이 아니라 **답 전체**가 들어오고 제목 · 목록 · 표가 마크다운이다
9. 사파리 주소창의 **주소 하나**만 복사해 붙인다 → 예전처럼 링크가 된다

**코드 블록 안의 줄 (200)**

10. 빈 줄에 ```` ``` ```` 를 치고 엔터, `# 주석` · `- 항목` · `**굵게 아님**` 을 한 줄씩 친 뒤 ```` ``` ```` 로 닫는다 → 그 사이 줄들이 **고정폭 글씨**이고 `#` · `-` · `**` 가 숨지 않고 그대로 보인다 (제목처럼 커지지 않는다)
11. 코드 덩어리 안의 `- 항목` 줄 끝에서 **엔터** → 다음 줄에 `- ` 가 저절로 붙지 않는다
12. 닫는 ```` ``` ```` 줄을 지운다 → 그 아래 줄들도 고정폭이 된다. 다시 치면 아래 줄들이 원래 모습으로 돌아온다

**제목 안의 서식 (201)**
