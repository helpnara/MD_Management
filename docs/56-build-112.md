**먼저 — 겉으로는 그대로여야 한다**

1. 노트 목록 · **고정된 노트** 묶음 · 폴더 화면의 **숫자**가 예전과 같다. 노트 하나를 열어 글자 하나를 치고 뒤로 → 그 노트가 목록 맨 위
2. 다른 노트에서 링크로 가리키는 노트를 **읽기**로 연다 → 맨 아래 **이 노트를 가리키는 노트** 목록이 예전과 같다
   (없으면 만든다: 노트 A 에 `[[` 로 노트 B 를 넣고 저장 → B 를 읽기로 열면 A 가 보인다)
3. 2 에서 A 의 링크를 **지우고** 2초 기다린 뒤 B 를 다시 읽기로 열면 A 가 **사라져 있다** (저장 하나만 색인해도 역링크가 따라온다)
4. 검색에서 전에 되던 말(제목 · 본문 · 초성) 셋을 다시 쳐 본다 → 결과가 같다 (색인을 새로 만들었다)
5. 사진이 든 노트 하나를 **휴지통**으로 보낸다 → 설정 → 휴지통에 노트와 사진이 함께 있고, 되돌리면 둘 다 돌아온다 (첨부 셈 그대로)
6. 사진이 **없는** 노트 하나를 휴지통으로 보낸다 → 바로 사라진다 (전체를 읽지 않으니 큰 폴더에서도 즉시)

8. `규모 시험` 폴더에서 노트 아무거나 하나를 **읽기 모드**로 연다 → 진단 정보 → **마지막 열기** 가 `0.xx초 (읽기 · 그리기 · 가리키는 노트)` — 가리키는 노트가 **0.0x초**
9. 노트 하나를 열어 글자를 몇 개 치고 2초 기다린다 → 진단 → 최근 일에 **색인 갱신: …개** 줄이 **쌓이지 않는다** (저장 하나는 조용히 그 노트만 색인)
