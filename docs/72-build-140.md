## 빌드 140 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

**준비.** 294 는 **아이패드 + 외장 키보드**로, 영상에 찍은 그 노트(`- [제목](긴 주소)` 항목이 여럿인 목록)로 본다. 295 는 아무 노트 하나에서 본다.

0. 설정 → **맨 아래** 회색 글이 `1.1.22 (140)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. **↓ 한 번씩 (294)** — 그 노트를 쓰기 화면으로 열고 제목 줄에 커서를 둔다 → ↓ 를 한 번씩 눌러 목록 끝까지 → 커서가 **한 줄씩** 내려간다 · 주소가 드러난 항목에서는 ↓ 두 번(주소 줄 → 다음 항목) · 처음이나 끝으로 **튀지 않는다**
2. **↓ 누르고 있기** — 제목 줄로 돌아가 ↓ 를 **꾹 누른 채** 끝까지 → 튀지 않는다 · 끝에서 ↑ 를 꾹 눌러 처음까지 → 튀지 않는다
3. 긴 링크 항목 사이의 **빈 줄**을 ↑↓ 로 몇 번 넘나든다 → 그대로
4. 설정 → 도움 → **진단** → 최근 일에 *쓰기 화면 — 커서 튐:* 으로 시작하는 줄이 **없다** (1 ~ 3 뒤). 있으면 그 줄을 복사해 보내 주세요 — 다시 난 것을 잡는 심판이다
5. **PDF 카드 (295)** — 아무 노트의 쓰기 화면 오른쪽 위 **···** → **문서 첨부** → PDF 하나 고르기 → `[이름.pdf](<assets/이름-1.pdf>)` 한 줄이 들어간다 → 그 줄 **맨 앞에 `!` 를 친다** → 읽기 화면 → **PDF 첫 쪽 그림과 파일 이름이 든 카드**가 보인다 (예전에는 빈칸)
6. 카드를 누르면 PDF 미리보기가 열리고 쪽을 넘길 수 있다 → 닫기
7. 쓰기 화면으로 돌아가 그 `!` 줄에 커서를 두면 **아래 사진 띠에 PDF 첫 쪽**이 작게 선다 (예전에는 안 섰다)
8. 같은 방법으로 **동영상이나 다른 문서** 하나를 문서 첨부 → `!` → 읽기 화면에 `MOV` · `DOCX` 같은 **종류 글자 + 이름 카드** → 누르면 미리보기
9. 5 의 줄에서 `!` 를 지운다 → 읽기 화면에서 예전처럼 **글 링크** 로 보이고 누르면 미리보기 (그대로)
10. 메모에서 가져온 노트 가운데 PDF 가 든 것을 읽기 화면으로 → 빈칸이던 자리에 **첫 쪽 그림 카드**가 선다 · 사진은 그대로 그림

**참고사항 (번호 없음)** — 껐다 켜도 `!` 를 붙인 줄 · 카드가 그대로 (파일은 안 바뀌었고 보이는 모습만 달라졌다) · 다른 앱에서 열어도 `![](…pdf)` 줄은 그대로다.
