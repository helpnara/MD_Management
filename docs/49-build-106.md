## 빌드 106 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1.7 (106)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. **사파리** 주소 칸에 `slowmargin://event` 를 치고 **이동** → *느린 여백에서 열겠습니까* 창이 뜨면 **열기** → **느린 여백이 열린다**
   (또는 아이폰 기본 **메모** 앱(노란 아이콘)에 적어 파란 링크가 되면 누른다. **이 앱의 노트에 적으면 링크가 되지 않는다** — 쓰기 화면은 글을 그대로 보여 준다.
   2026-10-15 사용자가 이 앱의 노트에 적어 *열리지 않는다* 고 알려 와 고쳐 적었다)
2. 열린 뒤 화면 아래 **붉은 띠 · 가져오지 못했다는 안내가 없고**, 보던 목록 · 노트가 그대로다
3. 설정 → 진단 정보 → **최근 일** 맨 위에 `앱 주소로 열림: slowmargin://event` 줄이 있다
4. 앱을 **완전히 닫는다**(앱 전환 화면에서 위로 밀기) → 1 의 링크를 다시 누른다 → 앱이 처음부터 열리고 목록이 평소처럼 뜬다 (붉은 띠 없음)
5. 파일 앱에서 이 앱 폴더의 `.md` 하나를 눌러 **느린 여백으로 연다** → 예전처럼 그 노트가 열린다 (파일 열기는 그대로)
