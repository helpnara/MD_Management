## 빌드 136 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

**준비.** 289 검토에 보내 주신 압축 파일(노트 2개)을 `파일` 앱에서 **앱 폴더 밖**(예: *다운로드*)에 두고 눌러 푼다 → `옮겨야 하는 MD파일` 폴더(안에 노트 이름 폴더 둘)와 `__MACOSX` 폴더가 생긴다.

0. 설정 → 진단 정보 → **판** 이 `1.1.21 (136)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. 앱을 처음 열면 아래 띠에 *검색 색인을 만드는 중* 이 잠깐 보일 수 있다 (색인 판이 바뀌어 처음부터 다시 만든다 — 290). 다 사라질 때까지 기다린다
2. 설정 → **노트** 구역 → *안 쓰는 첨부* 아래 **마크다운으로 내보낸 폴더 가져오기** → 고르는 창에서 `옮겨야 하는 MD파일` 폴더로 들어가 **열기** → 설정이 닫히고 같은 이름의 **새 폴더**가 열린다 · 아래 띠 *노트 2개 · 첨부 44개를 옮겨야 하는 MD파일 폴더로 가져왔습니다. 고른 폴더는 그대로 있습니다.*
3. 그 폴더의 노트 목록 — **노트 2개가 나란히** (노트 이름 폴더 · `Attachments` · `__MACOSX` 폴더가 목록에 없다). 폴더 목록으로 돌아가도 이 폴더 안에 하위 폴더가 안 보인다
4. 사진이 많은 노트를 읽기 화면으로 → **사진이 빠짐없이** 보인다 (35장) · 링크 하나를 누르면 그 웹 페이지가 열린다
5. 다른 노트(사진 9장)를 읽기 화면으로 → 사진 9장 · 제목과 목록(점)이 선다 · 오른쪽 위 **···** 에 **줄바꿈 고치기가 없다** (가져오며 이미 고쳤다)
6. 설정 → **안 쓰는 첨부** → 방금 가져온 사진이 **목록에 없다** (모두 노트가 쓰고 있다)
7. **찾기 (290)** — 노트 목록 ··· → *모든 노트에서 찾기* → `벤치마크` 를 친다 → **5 의 노트가 나온다** (이 낱말은 내보낸 파일에 NFD 로만 들어 있어 예전 빌드에서는 안 나왔다)
8. `파일` 앱 → *다운로드* 의 `옮겨야 하는 MD파일` 폴더가 **그대로** (노트 이름 폴더 둘 · 그 안 `Attachments`)
9. 2 를 **한 번 더** → 새 폴더 이름이 `옮겨야 하는 MD파일 2` · 처음 가져온 폴더는 그대로 (덮어쓰지 않는다). 확인 뒤 `… 2` 폴더는 폴더 줄을 왼쪽으로 밀어 **지우기** → 확인 (휴지통으로 간다)
10. 2 에서 노트 이름 폴더 안의 `Attachments` 폴더를 고른다 → 아래 띠 *고른 폴더에 노트(.md · .txt)가 없습니다. 압축 파일이면 파일 앱에서 먼저 눌러 풀어 주세요.* · 아무 폴더도 안 생긴다
