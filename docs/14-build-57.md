**앱 안에서**

1. 긴 노트를 **읽기 모드**로 열어 한참 내린 뒤, 위의 **쓰기** 단추 → 편집 화면 **맨 위에 방금 보던 문단**이 있다. 키보드는 안 올라온다
2. 편집 화면에서 한참 내린 뒤 **읽기** 단추 → 읽기 화면 맨 위에 **같은 문단**이 있다. 몇 번 오가도 자리가 흐르지 않는다
3. 긴 **코드 상자**나 **표** 한가운데를 맨 위에 두고 바꿔도 그 근처로 간다
4. 읽기 모드에서 `</>` 단추로 만든 코드 상자의 **긴 줄이 화면 폭에서 다음 줄로 접힌다** — 옆으로 밀리지 않는다
5. 폴더 A 에 **사진을 넣은 노트**를 만든다 → 그 사진 줄을 복사해 **폴더 B 의 노트에 붙인다** → 폴더 A 의 노트를 **지운다** → 폴더 B 노트의 **사진이 그대로 보인다**
6. 설정 → **휴지통** → 노트 아래에 **첨부 N개 · 용량** 칸과 사진 줄이 보인다. 사진 줄의 **되돌리기**를 누르면 휴지통에서 빠진다
7. 휴지통에서 **사진이 있던 노트** 하나를 왼쪽으로 밀어 **영구 삭제**(`지우기` 입력) → 첨부 칸의 개수가 준다
8. 노트에서 **사진 줄을 지운다** → 설정 → **안 쓰는 첨부** → 그 사진이 크기와 함께 있다 → 누르면 미리보기 → 왼쪽으로 밀어 **휴지통으로**(한 번 묻는다) → 휴지통의 첨부 칸에 보인다
9. 다른 폴더의 노트가 링크하고 있는 **폴더를 길게 눌러 이름 바꾸기** → 확인창에 *다른 폴더의 노트에 이 폴더 안을 가리키는 링크가 N개 있습니다* 가 보인다 (링크가 없으면 그 문장이 없다)
10. 설정 → 진단 정보 → **판** 이 `1.0.1 (57)`
