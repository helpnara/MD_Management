### 176 — `line-map-cases.json` → `lineMapCases` (15건)

읽기 HTML 의 블록마다 `data-line` · `data-line-end` (원문 줄, 0 부터, **머리말 줄 수를 더한다**).
블록: 제목 · 문단(빽빽한 목록의 숨은 문단은 뺀다) · 목록 항목 · 인용 · 코드 상자 · 표 · 표의 줄 · 가로줄. 날 HTML 은 뺀다.

- **쓰기 → 읽기**: 편집기 맨 위 줄 → `anchors[줄]` = (블록 번호 · 비율). 품은 블록이 여럿이면 **가장 안쪽.**
  블록 사이 빈 줄은 **다음 블록의 머리**, 끝의 빈 줄은 마지막 블록의 끝.
- **읽기 → 쓰기**: 웹뷰 맨 위 블록 · 비율 → `줄 = 시작 + ⌊비율 × 줄 수⌋`.
- **오가도 같은 줄**(블록 안의 줄 전부)을 `generate.py` 가 확인한다.

**Swift 에서 할 일.**
- `Core` — `MarkdownHTML.lineMap(markdown:)` 가 `swift-markdown` 원문 범위에서 같은 표를 낸다 → `lineMapCases` 로 대조.
  HTML 에 속성 붙이기: `HTMLFormatter` 는 속성을 못 받는다. **블록 여는 태그를 문서 순서로 세어** 표와 짝짓는다 —
  날 HTML 은 이미 이스케이프되므로(`NoteRewriter`) 가짜 태그가 섞이지 않는다. **개수가 다르면 속성을 안 붙이고** 비율로 물러선다.
- 앱 — 모드 단추(`RootView` 의 `isReading.toggle()`) 앞뒤에서 자리를 재고 넘긴다. 값 하나(`줄 번호`)만 `LibraryModel` 에 둔다.
  - 웹뷰: `evaluateJavaScript` 로 맨 위 `[data-line]` 요소와 그 안 비율을 묻는다 / 줄로 내린다.
  - 편집기: 줄 → 글자 자리 → 레이아웃 사각형 → `contentOffset`. 키보드는 **안 올린다.**
- **가정 A17** — `allowsContentJavaScript = false` 여도 앱이 넣는 `evaluateJavaScript` 는 돈다. 안 돌면 전체 높이 비율로만.
  CI 스크린샷에 *읽기에서 절반 내려 → 쓰기* 한 장을 더해 본다.

## 빌드 57 확인 목록 — **초안**

> §3-2: 확인할 것은 **착수 뒤 그 자리의 코드를 읽고** 손가락이 할 동작으로 고쳐 적는다. 아래는 뼈대다.

1. 읽기에서 한참 내려 → **쓰기** → 같은 문단이 맨 위에 있다 (키보드는 안 올라온다)
2. 쓰기에서 한참 내려 → **읽기** → 같은 문단이 맨 위에 있다
3. 긴 코드 상자 한가운데에서 바꿔도 코드 상자 그 부근이다
4. 폴더 A 의 노트를 폴더 B 로 옮긴 뒤, A 에 남은 **같은 사진을 쓰는 노트**를 지운다 → B 노트의 사진이 그대로 보인다
5. 휴지통에서 사진 있는 노트 **하나**를 영구 삭제 → 휴지통의 첨부 개수가 준다
6. 노트에서 사진 줄을 지운다 → 설정 → **안 쓰는 첨부**에 그 사진이 있다 → 휴지통으로 → 휴지통에서 보인다
7. 읽기 모드에서 긴 코드 줄이 화면 폭에서 접힌다 (좌우로 안 밀린다)
8. 다른 노트가 링크한 폴더의 이름을 바꾸면 링크 수를 알려 준다
