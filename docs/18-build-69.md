## 빌드 69 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

**굵게 (197)** — 쓰기 화면과 읽기 화면이 **같게** 보이는지 본다.

1. `하나의 **개인 기록(영어)**로` 를 친다 → 쓰기 화면에서 **굵게가 안 되고 `**` 가 글자로 보인다** (커서를 다른 줄로 옮겨도). 읽기 모드도 같다
2. `하나의 **개인 기록**(영어)로` — 괄호를 `**` 밖으로 → 쓰기 · 읽기 둘 다 **굵게**, `**` 는 안 보인다
3. `**굵게**는` → 둘 다 굵게 (예전과 같다)
4. `개인 기록(영어)` 를 골라 **굵게 단추**를 누른다 → `**개인 기록(영어)**` 로 감싸지지만, 바로 뒤에 조사가 붙어 있으면 1 처럼 **굵게가 안 된다** (`**` 가 보인다). 감싼 뒤 조사 앞에 빈칸을 넣으면 굵게가 된다

**밑줄 제목 · 이어지는 줄 (198)** — 제목 줄 **아래**에서.

5. `가나다` 를 치고 엔터, 다음 줄에 `---` → `가나다` 가 **제목 크기로 커지고**, 커서를 다른 줄로 옮기면 `---` 줄은 **빈 줄처럼** 안 보인다. 읽기 모드에서도 `가나다` 가 제목이다
6. 5 의 `---` 를 지운다 → `가나다` 가 보통 글로 돌아온다
7. 다시 `가나다` · `---` 를 만들고 그 사이에 **빈 줄**을 넣는다 → `가나다` 는 보통 글, `---` 는 흐린 줄로 남고, 읽기 모드에서 **가로줄**이 된다
8. `가나다` 다음 줄에 `===` → `가나다` 가 **더 큰 제목**이 된다
9. `할 일` 을 치고 엔터, **목록 단추**를 눌러 `- ` 를 넣는다 → `할 일` 이 **커지지 않는다**. 이어서 `우유` 를 치면 글머리표 항목이 된다
10. 9 에서 `우유` 를 치지 않고 `- ` 만 둔 채 **다른 줄을 누른다** → `할 일` 이 제목 크기로 커진다 (표준이 빈 `- ` 를 제목 밑줄로 읽는다 — 읽기 모드도 같다). `- ` 줄로 돌아와 글을 치면 돌아온다
11. `가나다` 다음 줄에 `2. 나` 를 친다 → 쓰기 화면에서 **번호 목록 모양이 아니라 보통 글**이다. 읽기 모드에서는 `가나다 2. 나` 가 **한 줄로 이어져** 보인다
12. 역따옴표 세 개 줄 · `가나다` · `---` · 역따옴표 세 개 줄 (코드 상자 안) → 쓰기 화면에서 `가나다` 가 **커지지 않는다**
13. 한 번 엔터로만 줄을 나눈 **긴 노트**(서른 줄 넘게) 끝에서 빠르게 쳐 본다 → 예전보다 **느려지지 않는다**

14. 설정 → 진단 정보 → **판** 이 `1.0.4 (69)`
