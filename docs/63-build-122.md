**셈이 그대로인가 (가장 중요 — 사진 · 링크가 깨지면 안 된다)**

1. 사진이 든 노트 하나를 **휴지통으로** → 설정 → 휴지통에 노트와 **사진이 함께** 있다 → 되돌리면 노트 · 사진 둘 다 돌아오고 사진이 보인다
2. 사진 줄(`![](assets/….jpg)`)을 복사해 **다른 노트에도** 붙인다 → 처음 노트를 휴지통으로 → 사진은 **남고** 다른 노트에서 그대로 보인다 → 확인 뒤 되돌린다
3. 휴지통의 사진 든 노트 하나를 **영구 삭제** → 휴지통 아래 *첨부* 수가 그만큼 준다 (같이 지워졌다)
4. 다른 폴더의 노트가 링크로 가리키는 폴더를 **길게 눌러 이름 바꾸기** → 확인창이 곧 뜨고 *이 폴더를 가리키는 링크 n개* 안내가 예전과 같다 → 바꾼 뒤 그 링크를 읽기에서 누르면 열린다
5. 그 폴더를 **다른 폴더 안으로 옮기기** → 4 와 같다 · 옮긴 폴더 안 노트의 사진 · 링크도 그대로 열린다
6. 5 뒤 찾기 칸에서 옮긴 폴더의 노트를 찾는다 → 결과 줄 아래 **새 폴더 이름** · 누르면 열린다 · 그 노트를 가리키는 노트(읽기 화면 맨 아래)도 그대로

**지운 폴더가 찾기에 남지 않는가 (271)**

7. 새 폴더 하나에 `가나다라마` 같은 낱말이 든 노트를 만든다 → **다른 폴더를 보는 채로** 그 폴더를 지운다 → 몇 초 뒤 찾기 칸에 그 낱말 → **결과가 없다** · 최근 고친 노트에도 없다

**노트가 많을 때 (규모 시험)**
