## 빌드 152 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → **맨 아래** 회색 글이 `1.1.26 (152)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. **실행 화면 (316)** — 앱을 완전히 껐다(앱 전환기에서 위로 밀기) 켠다 → 처음 잠깐 보이는 화면이 **흰색이 아니라 옅은 미색** (어두운 모드면 새까맣지 않은 따뜻한 검정)
2. **아이폰 폴더 화면 (316 · 320)** — 바탕이 옅은 베이지, 폴더 줄이 놓인 칸은 그보다 밝은 미색 → 맨 위 *폴더* 글자가 **명조**(획 끝에 삐침이 있는 굵은 글씨) → 위의 새 폴더 · 톱니 그림이 **초록**
3. **노트 목록 (318)** — 바탕 미색 → 맨 위 가운데 폴더 이름과 노트 **제목들이 명조**, 미리보기 · 날짜 · *노트 n개* 는 예전 글씨 → 올해 고친 노트의 날짜가 `11월 12일 오후 3:04` 처럼 **연도 없이** (작년에 고친 노트가 있으면 그 줄만 연도가 붙는다) → 모든 노트에서 찾기 칸에 낱말을 쳐서 나온 결과 줄 제목도 명조
4. **아이패드 고른 줄 (318)** — 노트 목록에서 노트를 누르면 그 줄이 회색 대신 **옅은 초록 둥근 칸** → 다른 노트를 누르면 칸이 옮겨 간다 → 왼쪽 폴더 칸은 **예전 모습 그대로** (떠 있는 유리 칸)
5. **쓰기 화면 (316 · 317)** — 바탕 미색 → 맨 위 가운데 노트 제목이 명조 → `# 제목` 줄과 `#` 없는 첫 줄이 **명조 굵게** → `##` · `###` 줄도 명조, `####` 는 예전 굵은 글씨 → 링크 글자가 초록 → 코드 덩어리 바탕이 옅은 베이지 → **명조 제목 줄 끝에서 한글을 친다** (예: `# 오늘의 회의` 뒤에 *메모*) → 글자가 조합되며 깨지거나 자모가 흩어지지 않는다
6. **읽기 화면 (317 · 319)** — 같은 노트를 읽기로 → 제목들이 **명조** → 할 일 상자를 눌러 켜고 끈다 → 상자 색이 **초록**이고, 누를 때마다 **제목 글씨가 사라졌다 나타나거나 고딕으로 바뀌었다 돌아오지 않는다** → 인용(`>`)의 세로선이 초록 → `---` 가로줄이 짧게 가운데 → 아이패드를 **가로로** 두고 노트만 크게 보면 글줄이 화면 끝까지 가지 않고 가운데 폭에서 접힌다
7. **어두운 모드 (316)** — 설정 앱 → 디스플레이 → 어둡게 → 앱으로 돌아온다 → 바탕이 새까맣지 않은 **짙은 먹색**, 글자는 미색, 초록이 밝은 잎색 → 폴더 화면 · 노트 목록 · 쓰기 · 읽기 · 설정을 한 번씩 → **흰 칸이나 회색 칸이 섞인 화면이 없다**
8. **설정 · 시트 (320)** — 설정을 연다 → 바탕 베이지 · 칸 미색 · 켜진 스위치가 **잎 초록** → 도움 → 사용법 · 단축키 · 진단 화면도 같은 바탕 → 노트 ··· → **노트 정보** · **안 열리는 링크 찾기** 시트도 같은 바탕 → 정리 → 휴지통도 같은 바탕
9. **확인창 · 찾기 막대** — 노트 줄을 밀어 *지우기* → 확인창의 단추 글자가 초록(지우기는 빨강) → 취소 → 노트를 열고 ··· → 노트 안에서 찾기 → 찾기 막대가 예전처럼 뜨고 찾는다
10. **큰 글자** — 설정 앱 → 손쉬운 사용 → 디스플레이 및 텍스트 크기 → 더 큰 텍스트로 크게 → 앱으로 돌아온다 → 목록 · 쓰기 · 읽기의 **명조 제목도 같이 커진다**

**참고사항 (번호 없음)** — 큰 변경 뒤 첫 빌드라 다시 올린다: 껐다 켜서 노트 · 북마크 · 색인이 그대로인가 · 다른 앱(파일)에서 열어도 글이 같은가 (보이는 모습만 바뀌었고 파일은 한 글자도 안 바뀐다). 앱 크기가 8MB 남짓 커진다 (명조 글꼴).
