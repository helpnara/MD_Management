## 빌드 96 사용자 확인 (2026-10-11) → 빌드 97

*복사 붙여넣기는 잘 되는데 크게 보기를 하면 가로 스크롤이 필요한 상황인데 자동 줄바꿈되어서 세로 스크롤 바만 사용할 수 있게* —
크게 보기 창이 글 전체를 `Text` 하나에 담고 `fixedSize(horizontal:)` 를 걸었는데 기기에서는 화면 폭에 맞춰 접혔다 (여기서는 재현 못 함).
→ **한 줄씩 그리고 줄마다 `lineLimit(1)` + `fixedSize`** — 접힐 수 없다. 모든 줄을 재는 `VStack` (`LazyVStack` 은 보이는 줄만 재 폭이 흔들린다).
창 안에서 글 고르기는 한 줄 안에서만 — 통째로는 위 **복사** 단추.

*원본을 코드 부분과 일반 글 부분을 동시에 복사하면 … 로직을 조금 더 가다듬을 필요가 있어* (첨부 두 장) — 붙이니 `코드` 만 든 상자가 하나 더 생겼다.
머리 줄의 `코드` 가 **페이지의 글**이라 함께 실렸고, 고정폭 글꼴이라 붙여넣기가 *고정폭 문단 = 코드* 로 읽었다 (파이썬 쌍둥이가 똑같이 재현).
→ 머리 글자를 **CSS 가 그린다** (`::before { content: attr(data-label) }`) — 눈에는 같고 복사에는 안 실린다. 머리 줄 전체를 고를 수 없게(`user-select: none`).
→ 붙여넣기 정답표에 그 꼴을 사례로 (*읽기 화면에서 코드 상자와 글을 함께 골라 복사* — 코드 상자 1 · 문단 2).

**코드 리뷰 (사용자 관점, 2026-10-11)** — 빌드 96 사용자 화면의 머리 줄 아래 **짙은 선**: 가름선 색(`--yb-rule`)이 웹으로 넘어갈 때 투명도가 빠졌다 (`Palette.cssTokens` 의 `hex`). 머리 줄 선만 옅게 (`color-mix`). 나머지 자리는 238.
