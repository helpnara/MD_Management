**만든 길.** 읽기 화면은 자바스크립트를 끈 웹뷰라 화면 안에서 클립보드에 넣을 수 없다 — 체크상자(211)와 같은 길: 단추는 `yb://copy/<번호>` · `yb://code/<번호>` 링크, 누르면 앱이 받는다.
**단추 번호와 복사할 글은 같은 한 번의 훑기에서 나온다** (CLAUDE.md §1) — 화면에 그린 HTML 에서 상자 글을 되돌려 얻는다. 원시 HTML 은 다 이스케이프되므로 진짜 `<pre>` 는 코드 블록에서만 나온다.
**쓰기 화면은 그대로다** — 머리 줄은 읽기 화면에만 그려지고, 파일에는 아무것도 들어가지 않는다.
