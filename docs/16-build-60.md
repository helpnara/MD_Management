### 180 — 글을 바꾸는 길 × 조합 상태

| 길 | 조합 없음 | 조합 중(밑줄) | 이전 |
|---|---|---|---|
| 도구 띠 (굵게 · 기울임 · 지움 · 코드 · 인용 · 표) | 그대로 | **확정 → 바꿈** | 조합 범위 옆을 바꿈 ❌ |
| 도구 띠 들여쓰기 · 내어쓰기 / 하드웨어 탭 · 시프트 탭 | 그대로 | **확정 → 바꿈** | ❌ |
| 노트 연결 (`>>` · `[[` 목록에서 고르기) | 그대로 | **확정 → 넣음** | 아무 일도 안 함 (막혀 있었다) |
| 붙여넣기 | 그대로 | **확정 → 붙임** (링크 고치기 · 바꿔 붙이기 그대로) | ❌ |

| 엔터 (목록 잇기) · 빈칸 (되돌리기 끊기) · 번호 맞추기 | 그대로 | 조합 중엔 안 함 (예전 그대로 — 입력기가 한 일이다) | — |

첨부 셈이 첨부를 놓치지 않게 (파서가 뽑은 것과 같은지 테스트가 본다).

## 빌드 60 확인 목록 — 코드를 읽고 적었다 (2026-09-29 착수)

1. 노트에 한글로 `가나다` 를 치고 **스페이스 없이 바로** 도구 띠의 **굵게(B)** 를 누른다 → 앱이 꺼지지 않고 `가나다` 가 그대로 있으며, 바로 뒤에 `****` 가 생기고 커서가 그 가운데에 선다 (이어서 치면 굵게)
2. 다시 한글을 치고 **바로** 도구 띠의 **인용** · **표** · **들여쓰기** 를 차례로 눌러 본다 → 매번 친 글자가 그대로 남고 앱이 꺼지지 않는다
3. 한글을 치고 **바로** 커서를 길게 눌러 **붙여넣기** → 친 글자 뒤에 붙는다
4. 사진첩에서 **세로로 찍은 사진**을 넣는다 → 쓰기 · 읽기 둘 다에서 **세로로 바로 서서** 보인다
5. 사진 줄에 커서를 둔다 → 아래 띠에 **작은 사진**이 보이고, 누르면 크게 열린다
6. 문서 첨부로 PDF 를 하나 넣는다 → 링크가 들어가고, 읽기 모드에서 누르면 열린다. (있으면) **1GB 넘는 영상**도 첨부 → 앱이 꺼지지 않고 링크가 들어간다
7. 굵게가 든 줄을 복사해 **메모 앱**에 붙인다 → `**굵게**` 처럼 **기호까지 원문 그대로** 들어간다
8. 폴더 A 노트의 사진 줄을 복사해 **폴더 B 노트**에 붙인다 → *링크 1개를 이 노트에서 열리도록 고쳤습니다* 가 뜨고 사진이 보인다 (7 을 바꿨으니 177 이 그대로인지)
9. 설정 → 진단 정보 → **판** 이 `1.0.2 (60)`

182 · 183 은 사람이 만들기 어려운 파일이라 **CI 정답표가 본다** (`nestingCases` · CRLF 사례).
