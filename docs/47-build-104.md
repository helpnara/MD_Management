- 메모는 동영상을 HTML 에 `<object data="file:///app-preview-886x1920.mp4">app-preview-886x1920.mp4</object>`, 사진을 `<img src="file:///IMG_6846.png">` 로 싣고,
  서식 있는 글(RTFD)에는 첨부 둘을 **동영상 · 사진** 차례로 실었다. 평문에는 첨부 자리 글자(U+FFFC)가 없고 빈 줄뿐이다.
- 변환이 `<object>` 를 몰라 **안의 파일 이름을 보통 글로** 붙였다 (첫째 줄). 첨부 자리는 `<img>` 하나만 세어(*자리 1개 · 첨부 2개*)
  **첫 첨부(동영상)가 사진 자리에** 들어갔다 (파란 링크) — 사진은 빠졌다.
