## 빌드 113 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1.11 (113)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. 진단 정보 → **폴더** 칸에 **금고 파일 N개** 줄이 새로 있다 (노트 + 사진 · 첨부 수 — 지금 금고면 수백 개). 뒤에 *거기까지만 셌습니다* 가 **없다**
2. 설정 → 시험 도구 → 규모 시험 → **노트 3000개 만들기** (작은 노트 · 약 18MB — iCloud 가 올린다) → 끝나면 진단 정보의 **금고 파일** 이 **3,000개를 넘는** 수다 (예전 같으면 2,000 에서 멈췄다)
3. 규모 시험 **밖의** 노트 하나를 쓰기로 연다 → 도구 띠 **링크** 단추 → 파일 고르기 검색 칸에 `시험 3000` → **시험 3000.md** 가 보인다 (`시험 1` · `시험 1500` 도 쳐 본다 — 다 나온다)
4. 3 에서 **시험 3000.md** 를 눌러 링크를 넣는다 → 노트 오른쪽 위 `…` → **안 열리는 링크 찾기** → *안 열리는 링크가 없습니다*
5. 읽기로 넘겨 그 링크를 누른다 → 시험 3000 노트가 열린다
6. 다 보면 규모 시험 폴더를 휴지통으로 보내고 설정 → 휴지통에서 영구 삭제 → 진단의 **금고 파일** 이 1 의 수로 돌아온다

**참고사항 (번호 없음)** — 3,000개를 만드는 동안과 직후 처음 색인이 돈다 (1,000개 4.26초 — 3,000개면 10초 남짓). 그동안 연 노트는 *마지막 열기* 의 읽기가 길게 나올 수 있다 (줄 선 시간 · 빌드 112 와 같다).
