## 빌드 147 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → **맨 아래** 회색 글이 `1.1.23 (147)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. **어느 폴더의 노트 하나**를 연다 (그 폴더 이름을 기억해 둔다 — 예: 일기) → 쓰기 화면 `···` → **문서 첨부** → 창 제목이 **`옮겨야 하는 MD…` 가 아니라 그 노트의 폴더 이름**이다 (맨 위 폴더의 노트면 `Slow Margin`)
2. 제목 옆 **⌄** → 이번에는 **위 폴더들(Slow Margin · iCloud Drive 등)** 이 줄지어 나온다 → **iCloud Drive** 를 누르면 그리로 옮겨 간다
3. 거기서 아무 폴더나 눌러 **들어가고**, 왼쪽 위 **`<`** 로 방금 있던 곳으로 돌아온다 (이제 지나온 기록이 있어 켜져 있다)
4. 다른 폴더 안의 파일(PDF · 사진) 하나를 골라 **열기** → 노트의 커서 자리에 링크 한 줄
5. 다른 폴더의 노트로 가서 다시 **문서 첨부** → 이번에는 **그 노트의 폴더**에서 열린다 (4 에서 들어갔던 곳이 아니다)
6. 자판을 올린 채로 문서 첨부를 눌러도 자판이 내려가고 창 아래까지 보인다 (빌드 146 그대로)

**참고사항 (번호 없음)** — `옮겨야 하는 MD파일` 폴더는 아이클라우드의 *최근 삭제된 항목* 에 있다. 그 안의 파일이 필요하면 파일 앱 → 둘러보기 → **최근 삭제된 항목** 에서 길게 눌러 **복구**한 뒤 쓰면 된다. 필요 없으면 그대로 두면 30일 뒤 사라진다.
