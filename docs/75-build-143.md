## 빌드 143 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

**준비.** **아이패드 + 외장 키보드**, 영상의 그 노트(`- [제목](긴 주소)` 항목이 여럿). 빌드 142 에서 꺼진 동작을 먼저 본다.

0. 설정 → **맨 아래** 회색 글이 `1.1.22 (143)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. **↓ 누르고 있기 (빌드 142 에서 꺼진 자리)** — 제목 줄에서 ↓ 를 **꾹 누른 채** 목록 끝까지, 끝에서 ↑ 를 꾹 눌러 처음까지 → 앱이 **안 꺼지고** 한 줄씩 · 튀지 않는다. 두어 번 되풀이
2. **주소가 드러난 항목 안에서** — 링크 항목에 커서를 두면 주소가 드러나 두 줄이 된다 → 그 첫 줄에서 ↓ → 둘째 줄(주소 줄) → ↓ → 다음 항목. ↑ 로 되돌아온다. 꾹 눌러도 같다
3. **문단 끝에서 ↑** — 어느 항목의 맨 끝에 커서 → ↑ → 바로 위 줄 (오른쪽으로 옮기지 않아도)
4. **가로 자리 기억** — 긴 항목의 가운데쯤 → ↓ 로 빈 줄을 지나 다음 긴 항목 → 원래 가로 자리 근처
5. **고르기는 그대로** — ⇧↓ 두 번 → 두 줄이 골라진다 → 풀기
6. 마지막 항목에서 ↓ → 글 끝 · 제목 줄에서 ↑ → 글 처음
7. 설정 → 도움 → **진단** → 최근 일에 *쓰기 화면 — 커서 튐:* 줄이 **없다** (1 ~ 6 뒤). 있으면 복사해 보내 주세요
8. 빌드 141 의 **문서 첨부 창에서 폴더 들어가기**(296)와 **다른 첨부 카드**(295)를 아직 안 보셨으면 여기서
