## 2. 설문 답

| 칸 | 답 | 근거 |
|---|---|---|
| 카테고리 (기본) | **생산성** | |
| 카테고리 (보조) | 안 고름 | 억지로 채우지 않는다 |
| 연령 등급 | **4+** — 모든 항목 *없음* | 사용자가 쓴 글만 보여 준다 |
| 가격 | **무료** | |
| 판매 지역 | **대한민국** 하나로 시작해도 되고 전체도 된다 | 한국어 설명뿐이라 한국부터가 자연스럽다 |
| 저작권 | `2026 helpnara` 꼴 | |

### ⚠️ 개인정보 설문 — **여기가 제일 조심할 곳**

**처리방침과 한 글자도 어긋나면 안 된다.** `docs/privacy.md` 는 *어떤 개인정보도 수집하지
않습니다* 라고 말한다. 그러니 설문도 **데이터를 수집하지 않음**이어야 한다.

| 물음 | 답 |
|---|---|
| 이 앱이 데이터를 수집합니까 | **아니요** |

**정말 아닌지 코드로 따져 보면:**

- 서버가 없다. 네트워크 호출이 없다 (`project.yml` 의 수출 규정 답변 근거와 같다)
- 분석 · 광고 식별자를 안 쓴다
- iCloud 동기화는 **애플이** 하고, 개발자는 그 내용을 못 본다 — 애플 기준으로도
  **개발자가 수집하는 것이 아니다**
- 사진 · 문서 권한은 **사용자가 고른 것만** 읽고 폴더 안에 둔다. 밖으로 안 보낸다

## 3. 심사 메모

```
이 앱은 서버를 쓰지 않습니다. 모든 글은 사용자의 iCloud Drive 폴더에 마크다운 파일로
저장됩니다. 계정이나 로그인이 없으므로 심사용 계정이 필요하지 않습니다.

처음 실행하면 앱 전용 iCloud 폴더가 만들어지고 견본 노트가 한 개 들어갑니다. 바로 열어
보실 수 있습니다. 설정에서 다른 폴더를 고를 수도 있습니다.

주요 기능:
- 마크다운 파일을 그대로 열어 읽고 고칩니다. 커서가 있는 줄만 원문으로 보입니다.
- 사진과 문서를 노트 옆 assets 폴더에 넣고 본문에 링크합니다.
- 노트 제목으로 다른 노트를 찾아 링크합니다.
- 본문과 제목을 함께 검색합니다.
```

> **기능 목록을 넣어 둔 까닭.** 메모 앱은 *기능이 너무 단순하다*(4.2)로 걸리는 일이 있다.
> 무엇을 하는 앱인지 심사자가 한눈에 보게 적어 둔다.
