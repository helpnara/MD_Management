## 빌드 110 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1.9 (110)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. 카카오맵 앱에서 장소 하나 → **공유 → 복사** → 노트를 쓰는 화면 빈 줄에 **붙여넣기** → `[장소 이름](<https://kko.to/…>)` 한 줄 · 아래 띠 *지도 장소를 링크로 만들었습니다*
2. 카카오맵 **두 곳**(사이에 빈 줄)을 한 번에 복사해 붙여넣기 → **두 줄**, 사이에 빈 줄 하나
3. 카카오맵 두 곳이 **한 줄에 붙은** 글을 복사해 붙여넣기 → 역시 **두 줄**
4. 네이버지도 두 곳 예시 글을 다시 붙여넣기 → 빌드 109 의 3 과 같이 두 줄 (셈을 바꿨으니 한 번 더)
5. 읽기로 넘긴다 → 장소마다 **한 줄씩** 파란 링크(장소 이름) · 네이버는 뒤에 `: 주소` → 링크를 누르면 지도 앱 또는 사파리가 열린다
6. `오늘 갈 곳` 줄 아래에 카카오맵 글을 둔 것을 복사해 붙여넣기 → 바꾸지 않고 **복사한 글 그대로** (띠 없음)
7. 카카오맵 앱에서 장소 → **공유 → 느린 여백** → 넣을 곳에서 **고정한 노트** 하나 → 그 노트 맨 끝에 `- [장소 이름](<https://kko.to/…>)` 목록 한 줄

**1 · 2 · 3 이 그대로 안 바뀌면** — 붙여넣은 직후 설정 → 진단 정보 → 맨 아래 **마지막 붙여넣기** 의 **결과** 가 `지도 머리말이 있지만 장소로 못 읽음` 이다 →
**붙여넣은 서식 복사** 를 눌러 대화창에 붙여 보내 주세요 (장소 이름 · 주소만 담긴다).

**참고사항 (번호 없음)** — 되돌리기(세 손가락으로 왼쪽으로 쓸기)는 붙여 넣은 것을 통째로 지운다. 새 아이콘(251) · 네이버 공유 → 새 노트(빌드 109 의 7)는 그대로.
