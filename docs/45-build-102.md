## 빌드 102 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1.4 (102)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. 노트 하나를 쓰기 모드로 열어 한 글자 치고 왼쪽 위 **‹** 로 목록에 돌아온다 → **아무 창도 뜨지 않는다**. 설정 → 진단 정보 → 최근 일에 `평가 부탁 창을 부름` 이 **없다** (처음 며칠은 묻지 않는다)
2. 아이패드면 노트 A 를 고친 뒤 노트 B 를 연다 → 역시 아무 창도 없다

**참고사항 (번호 없음 · 며칠 뒤)** — 서로 다른 **5일** 노트를 저장하고 **7일**이 지난 뒤, 고친 노트에서 나오면 최근 일에 `평가 부탁 창을 부름 (1.1.4)` 이 **한 번** 남는다.
테스트플라이트라 창 자체는 뜨지 않는다 — 스토어 판에서만 애플이 띄운다. 날 수는 1.1.4 를 깐 뒤 첫 저장부터 센다.
