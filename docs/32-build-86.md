## 빌드 86 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.0.8 (86)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터

**아이패드 (가로 · 세 칸)**

1. 왼쪽 폴더 칸에서 최상위 폴더(예: `회의`)를 고른 채 **폴더 칸 위의 폴더+ 단추** → 창에 *회의 안에 폴더를 만듭니다* → 이름 `시험` → 만들기 → 폴더 칸에서 `회의` **아래**에 `시험` 이 생긴다
2. 폴더 칸에서 1 의 `시험` 을 고른 채 폴더+ 단추 → 창에 *폴더는 두 단계까지라 회의 안에 만듭니다* → 이름 `시험2` → `회의` 아래에 `시험` 과 **나란히** 생긴다
3. 폴더 칸 맨 윗줄(맨 위 폴더 이름)을 고른 채 폴더+ 단추 → 창에 **맨 위에 폴더를 만듭니다** → 맨 위에 생긴다
4. 가운데 노트 목록 칸 위의 폴더+ 단추도 1~3 과 같은 자리에 만든다

**아이폰**

5. 폴더 화면(맨 처음 화면) 위의 폴더+ 단추 → 창에 **맨 위에 폴더를 만듭니다** → 맨 위에 생긴다
6. 최상위 폴더의 노트 목록 화면에서 폴더+ 단추 → 창에 *<그 폴더> 안에 폴더를 만듭니다* → 그 폴더 아래에 생긴다 (빌드 85 와 같다)

정리: 확인에 만든 폴더는 길게 눌러 **지우기**로 치운다.
