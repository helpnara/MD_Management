## 빌드 107 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1.8 (107)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. 노트 목록에 **고정된 노트** 가 둘 이상인지 본다 — 모자라면 노트 줄을 **왼쪽으로 밀어 고정** 을 누른다
2. 고정된 노트 묶음의 **맨 아래** 노트를 열어 글자 하나를 치고 왼쪽 위 뒤로 → 그 노트가 고정된 노트 묶음 **맨 위** 에 있다
3. 아래 **노트** 묶음(고정 안 된 것)도 예전처럼 방금 고친 것이 위에 있다 — 두 묶음이 같은 규칙이다
4. 앱을 완전히 닫았다 다시 연다 → 고정된 노트 차례가 2 에서 본 그대로다 (최근 고친 순)
5. 오래전에 고친 노트 하나를 새로 **고정** 한다 → 고정된 노트 묶음의 **맨 위가 아니라** 그 노트를 고친 시각 자리(대개 아래쪽)에 들어간다
   — 예전에는 새로 고정한 것이 맨 위였다. 이제는 고친 순이라 이것이 맞다
6. 사파리에서 아무 쪽 **공유 → 느린 여백 → 넣을 곳** → **고정한 노트** 묶음의 차례가 목록의 고정된 노트 차례와 같다 (2 에서 고친 노트가 맨 위)

**참고사항 (번호 없음)** — 다른 기기에서 고정 노트를 고친 뒤 이 기기 목록을 당겨 새로 고치면 그 노트가 위로 온다.
