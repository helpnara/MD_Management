**스페이스 두 번 → 마침표 (217)** — 아이폰 설정 → 일반 → 키보드 → **“.” 단축키** 가 켜져 있을 때

1. 쓰기 화면에서 `오늘은 맑음` 을 치고 **스페이스를 빠르게 두 번** → `오늘은 맑음. ` 처럼 마침표와 빈칸이 된다
2. 아이폰 설정에서 **“.” 단축키를 끄고** 같은 동작 → 빈칸만 둘 들어간다 (확인한 뒤 다시 켜 두세요)
3. 번호 목록 `1. 가` · `2. 나` · `3. 다` 세 줄을 쓰고, 첫 줄 맨 앞의 `1. ` 을 지운 뒤 `5. ` 를 다시 친다 → 아래 두 줄이 `6.` · `7.` 로 바뀐다
