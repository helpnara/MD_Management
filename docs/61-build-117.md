## 빌드 119 확인 목록 — 사용자 관점 (코드를 읽고 적었다 · 117 · 118 의 것을 합쳤다)

0. 설정 → 진단 정보 → **판** 이 `1.1.13 (119)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터

**두 화면의 찾기 칸이 같다**

1. 폴더 화면과 노트 목록 화면 **둘 다** 맨 위 막대 바로 아래에 **같은 모양의 둥근 찾기 칸** (돋보기 · *모든 노트에서 찾기*) — 폭 · 밝기 · 자리가 같다. 노트 목록에서도 **당기지 않아도** 보인다
2. 두 화면 모두 목록을 위로 밀어도 칸은 **그 자리에 남는다**
3. 어두운 화면에서도 칸과 안내 글이 또렷하다

**넘어갈 때 (265)**

4. 폴더 하나를 눌러 들어가고 뒤로 나온다 → 칸이 화면과 함께 움직이고, **글자만 먼저 나오거나 아래로 튀거나 흐리게 남지 않는다**

**칸이 하는 일**

5. 폴더 화면 칸을 누른다 → 글쇠판 · **최근 고친 노트** · 칸 오른쪽 **취소** → 취소 → 폴더 목록 · 글쇠판이 내려간다
6. 낱말을 친다 → 결과 · 칸 안 **ⓧ** 로 글이 지워진다
7. 결과나 최근 고친 노트를 누른다 → 글쇠판이 내려가며 **한 번에** 노트로 · *노트를 열 때 읽기 모드로* 설정대로 열리고 링크가 된다 (빌드 116 과 같음)
8. 노트 목록 화면 칸에서 찾아도 결과가 같고, 결과를 누르면 글쇠판이 내려가며 노트가 열린다 · 취소 → 그 폴더의 노트 목록으로 돌아온다

**아이패드** (있으면)

9. 왼쪽 폴더 칸 맨 위에 같은 모양의 칸 · 가운데 노트 목록에는 칸이 없다 · (외부 키보드) `⌘F` → 왼쪽 칸이 보이며 칸에 글쇠가 간다
