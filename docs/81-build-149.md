## 빌드 149 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

1. **마지막 노트로 (302 · 아이폰)** — 설정 → 노트 → **앱을 열면 마지막 노트로** 가 켜진 채 → 하위 폴더의 노트(예: 주간 회의)를 연다 → 앱을 **완전히 끈다**(앱 전환 화면에서 밀어 올리기) → 다시 연다 → **아무것도 누르지 않아도** 그 노트가 열려 있다 → 뒤로 가기 = 그 폴더의 노트 목록 → 한 번 더 = 폴더 목록
