## 빌드 149 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → **맨 아래** 회색 글이 `1.1.24 (149)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. **마지막 노트로 (302 · 아이폰)** — 설정 → 노트 → **앱을 열면 마지막 노트로** 가 켜진 채 → 하위 폴더의 노트(예: 주간 회의)를 연다 → 앱을 **완전히 끈다**(앱 전환 화면에서 밀어 올리기) → 다시 연다 → **아무것도 누르지 않아도** 그 노트가 열려 있다 → 뒤로 가기 = 그 폴더의 노트 목록 → 한 번 더 = 폴더 목록
2. 최상위에 있는 노트(예: 특수문자)를 연 채 끄고 켜도 같다 — 그 노트가 바로 · 뒤로 가기 = 최상위 목록
3. 스위치를 **끄면** 예전처럼 노트 목록으로 열린다
4. 스위치를 켠 채 노트 하나를 열었다가 **그 노트를 지우고**(휴지통으로) 앱을 끄고 켠다 → 오류 띠 없이 예전처럼 목록으로 열린다
5. **단축키 화면 (313)** — 설정 → 도움 → **단축키** → 세 구역 *어디서나* (⌘N ⌘⇧N ⌘F ⌘E ⌥⌘↑ ⌥⌘↓ Esc) · *쓰기 화면* (⌘B ⌘I ⌘K ⌘⇧D Tab ⌘] ⇧Tab ⌘[) · *iOS 가 주는 것* → 설정 → 도움 → 사용법의 *외장 자판* 주제는 이 화면으로 가라는 한 줄뿐
6. **⌘ 목록 (309 · 아이패드)** — 노트를 **쓰기 화면**으로 연 채 외장 자판의 **⌘ 를 1초쯤 누르고 있는다** → 화면 가운데에 단축키 목록이 뜨고 *노트* 묶음(새 노트 · 새 폴더 · 찾기 · 읽기와 쓰기 오가기 · 이전 · 다음 노트)과 *쓰기* 묶음(굵게 · 기울임 · 링크 · 날짜 · 시각 · 들여쓰기 · 내어쓰기)이 보인다 → **읽기 화면**에서 누르면 *쓰기* 묶음이 흐리다
7. 단축키를 옮겼으니 **한 번씩 눌러 본다** (한 번만 눌리는지) — 쓰기 화면에서 글자를 골라 **⌘B** → `**` 로 한 번 감싸인다(두 번 감싸이거나 풀리면 안 됨) · **⌘I** · **⌘K** → 링크 고르기 · **⌘⇧D** → 날짜 한 줄 · 목록 줄에서 **⌘]** **⌘[** · **⌘E** → 읽기 ↔ 쓰기 · **⌘N** → 새 노트 · **⌘⇧N** → 새 폴더 창 · **⌘F** → 찾기 (아이폰은 노트를 연 채면 시트) · **⌥⌘↓ ⌥⌘↑** → 다음 · 이전 노트
8. 읽기 화면에서 **⌘]** · **⌘⇧D** → 아무 일 없음 (쓰기 묶음은 꺼져 있다)

**참고사항 (번호 없음)** — 아이패드에서도 1 ~ 2 는 같아야 한다 (폴더 칸을 접어 둔 채 끄고 켜도).
