## 빌드 94 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1.1 (94)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터

**읽기 화면이 방금 친 글을 보여 주나 (229)** — 이번에 읽기 페이지를 그리는 때를 바꿨다. 가장 먼저 본다

1. 노트를 쓰기 모드로 열어 맨 끝에 `가나다` 를 치고 **곧바로** 위 오른쪽 **읽기** → 읽기 화면 맨 끝에 `가나다` 가 있다
2. **쓰기** 로 돌아가 `라마바` 를 치고 **5초쯤 기다린 뒤** 읽기 → `라마바` 까지 있다
3. 읽기 화면에서 체크상자 하나를 누른다 → 바로 켜지거나 꺼진다. 쓰기로 가면 그 줄의 `[ ]` · `[x]` 도 바뀌어 있다
4. (참고) 긴 노트를 쓰기 모드로 열고 빠르게 여러 줄 쳐 본다 → 글자가 손가락을 늦게 따라오지 않는다

**도구 띠 단추 (231)**

5. 쓰기 화면 아래 띠의 **굵게(B)** 를 누르고 **떼지 않는다** → 누르는 동안 단추가 흐려지고, 반 초쯤 지나면 띠 위에 `굵게` 가 뜬다. 떼도 글에 `**` 가 안 생긴다
6. 굵게를 **짧게** 누른다 → 예전처럼 굵게가 걸리고 단추가 파란 칸이 된다. 키보드는 그대로 떠 있다
7. 띠를 왼쪽으로 끝까지 민다 → 밀리기만 하고 서식은 안 걸린다. **목록 모양**(점 세 줄)을 길게 → 네 가지 메뉴. 띠 높이는 예전과 거의 같다

**사진을 넣는 사이 노트를 바꾸면 (228)** — 틈을 맞춰야 해서 안 맞으면 넘어간다

8. 노트 A 를 쓰기 모드로 열고 `…`(아이패드는 **넣기** 단추) → **사진첩에서** → 사진을 **10장쯤** 골라 추가 → 창이 닫히자마자 **곧바로** 목록으로 나와 노트 B 를 연다 →
   B 에 사진 줄이 생기지 않고 화면 아래 붉은 띠에 `사진을 저장하는 사이 다른 노트로 넘어가 본문에는 넣지 않았습니다. 사진은 A 옆 assets 폴더에 있습니다.`
   (넣기가 먼저 끝나면 A 에 사진이 들어가 있다 — 예전과 같은 정상 동작이다)

**태그 색 (232)**

9. 밝은 화면에서 본문에 `#할일` 을 쓴다 → 쓰기 · 읽기 화면 모두 `#할일` 이 예전보다 **짙은 황토색**이다 (어두운 화면은 예전 그대로 밝은 노랑)

**보이스오버 (232) — 선택.** 시리에게 *보이스오버 켜 줘* · 끌 때 *보이스오버 꺼 줘*

10. 읽기 화면의 체크상자에 손가락을 댄다 → `체크상자, 꺼짐`(켜진 것은 `켜짐`)처럼 읽는다 (예전에는 *링크*). 고정한 노트 줄에 손가락을 대면 제목 뒤에 `고정됨` 이 함께 읽힌다 (예전에는 *핀* 같은 아이콘 이름)

**아이패드 키보드 (230)** — 하드웨어 키보드가 있을 때만

11. 쓰기 화면에서 낱말을 골라 **⌘B** → 굵게(`**낱말**`) · **⌘I** → 기울임. **⌘K** → *이미 있는 파일 연결* 창
12. 왼쪽 위 칸 단추로 폴더 · 목록 칸을 접어 **노트만 크게** 본 채 **⌘F** → 노트 목록 칸이 나오고 검색 칸에 커서가 선다
13. 같은 상태에서 **⌘N** → 새 노트가 생겨 열린다

**227 (iCloud 를 늦게 잡은 날)** 은 확인 목록에 넣지 않았다 — 설치 직후 iCloud 가 늦게 준비되는 때에만 생기는 길이라 일부러 만들 수 없다.
