## 빌드 124 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1.17 (124)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터

새 노트 하나에 아래 세 줄을 적고 시작한다 (번호는 직접 쳐도 되고 엔터로 이어도 된다).

```
1. 가
2. 나
3. 다
```

1. (사용자 사례) `1. 가` 줄의 **`1` 앞**을 눌러 커서를 둔다 → 엔터 → **위에 빈 줄**이 생기고 목록은 `1. 가` · `2. 나` · `3. 다` 그대로 (`2. 1.` 이 안 생긴다) · 커서는 `1` 앞에 그대로
2. 되돌리기(세 손가락으로 왼쪽으로 쓸기) → 빈 줄이 없어지고 원래 세 줄로 돌아온다
3. `2. 나` 줄의 **`2` 앞**에서 엔터 → `1. 가` · 빈 줄 · `2. 나` · `3. 다` — 번호가 밀리지 않는다 → 되돌린다
4. `1. 가` 줄의 **`1` 과 `.` 사이**에 커서 → 엔터 → 위에 빈 `1. ` 항목이 생기고 아래가 `2. 가` · `3. 나` · `4. 다` · 커서는 `2. ` 뒤 `가` 앞 → 되돌리기(세 손가락 왼쪽으로 쓸기)로 원래대로
5. `1. 가` 줄의 **`가` 바로 앞**에서 엔터 → 4 와 같다 (예전과 같은 동작) → 되돌린다
6. `2. 나` 줄의 **`나` 뒤**(줄 끝)에서 엔터 → 아래에 `3. ` 이 생기고 원래 `3. 다` 는 `4. 다` → 빈 `3. ` 에서 엔터 → 목록에서 나와 보통 줄이 된다 (예전과 같다)
7. 글머리 목록 `- 사과` 줄의 **`-` 앞**에서 엔터 → 위에 빈 줄 · `- 사과` 그대로 (예전에는 `- - 사과` 로 목록 안에 목록이 생겼다)
8. 할 일 목록 `- [ ] 할 일` 줄의 **맨 앞**에서 엔터 → 위에 빈 줄 · 체크 칸 그대로 하나
9. 들여쓴 항목(`- 가` 아래 탭으로 들인 `- 나`)의 **맨 앞**에서 엔터 → `- 나` 가 들여쓴 채로 한 줄 내려간다
10. 읽기 모드로 → 1 ~ 9 를 한 목록들이 번호 · 점 · 체크 칸으로 바르게 보인다
