## 빌드 89 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1 (89)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터

**도구 띠 단추 이름 (220) — 한국어 그대로**

1. 아무 노트나 쓰기 모드로 열고, 아래 도구 띠의 **굵게(B)** 단추를 **반 초쯤 누르고 있다가** 뗀다 → 띠 바로 위 가운데에 `굵게` 가 떴다가 1~2초 뒤 사라진다. 글에는 아무것도 안 생긴다 (`**` 가 안 붙는다)
2. 같은 단추를 **짧게** 누른다 → 예전처럼 굵게가 걸리고 단추가 파랗게 눌린 모습이 된다. 키보드는 그대로 떠 있다
3. 도구 띠를 왼쪽으로 끝까지 민다 → 미는 동안에는 이름이 뜨지 않는다. 맨 끝 **들여쓰기** 단추를 길게 → `들여쓰기`
4. **목록 모양** 단추(점 세 줄)를 길게 → 예전처럼 네 가지(글머리표 · 번호 · 체크상자 · 목록 해제) 메뉴가 뜬다

**앱이 짓는 이름 — 한국어 그대로인가**

5. 노트 목록 위 **새 노트** 단추 → 목록에 `새 노트` 가 생기고, 열린 노트의 첫 줄이 `# 새 노트`
6. 쓰기 화면에서 `[[가나다` 를 친다 → 아래 띠 끝에 `가나다 — 새 노트` 가 보인다 (누르지 않고 지워도 된다)

**영어로 바꿔서** — 아이폰 **설정** 앱 → 아래로 내려 **느린 여백** → **언어** → **English**

7. 앱을 열고 노트 목록 위 **New Note** → 목록에 `New Note` 가 생기고 첫 줄이 `# New Note`
8. 쓰기 화면에서 **굵게(B)** 단추를 길게 → 띠 위에 `Bold`
9. 쓰기 화면에서 `[[abc` 를 친다 → 아래 띠 끝에 `abc — New Note`
10. 사파리에서 아무 쪽이나 열고 **공유 → Slow Margin** 으로 보낸 뒤 앱으로 돌아온다 → 새 노트가 **이미 있는 `받은 글` 폴더**에 들어간다 (`Inbox` 폴더가 새로 생기지 않는다).
    위에 `Added shared items to the 받은 글 folder as new notes (1).` 이 뜬다
11. 설정 → **Language** → 한국어로 되돌린 뒤 10 처럼 한 번 더 보낸다 → `받은 글` 폴더에 들어가고 `공유로 받은 글 1개를 받은 글 폴더에 새 노트로 넣었습니다.`
