## 빌드 135 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

**준비.** 분석에 보내 주신 노트(아직 안 고친 것)가 앱 폴더에 있어야 한다. 파일 앱에서 그 노트를 길게 눌러 **복제** 해 두 벌로 만든다 — 하나는 쓰기 화면, 하나는 읽기 화면에서 고친다.

0. 설정 → 진단 정보 → **판** 이 `1.1.20 (135)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터
1. **붙여넣기** — 안 고친 노트를 쓰기 화면으로 열어 `## 1일차` 부터 몇 줄을 골라 복사 → 새 노트에 붙여넣기 → 아래 띠에 *보이지 않는 줄바꿈 · 빈칸 글자 n개를 고쳤습니다. 되돌리기로 무를 수 있습니다.* · 붙인 `## 1일차` 가 **큰 제목**, `-` 줄이 **목록**으로 보인다
2. **쓰기 화면에서 고치기** — 안 고친 노트(첫 벌)를 쓰기 화면으로 → 오른쪽 위 **···** → *이 노트* 묶음 맨 위에 **줄바꿈 고치기** → 누른다 → 아래 띠 *보이지 않는 줄바꿈 · 빈칸 글자 2667개를 고쳤습니다. 되돌리기로 무를 수 있습니다.* (숫자는 `2,667` 로 보일 수 있다) · 커서가 있던 자리 그대로 · `## 2일차` 같은 줄이 이제 **그 줄만** 큰 제목 (예전에는 그 덩어리 전체가 제목 모양)
3. 2 바로 뒤 **되돌리기** (아이패드 외장 키보드 ⌘Z · 아이폰은 세 손가락으로 왼쪽 쓸기) → 한 번에 고치기 전으로 · 다시 ⌘⇧Z(또는 세 손가락 오른쪽) → 고친 모습
4. 몇 초 뒤(자동 저장) 다시 **···** → **줄바꿈 고치기가 없다**
5. 읽기 화면(위 책 단추) → `1일차` · `2일차` … 가 **제목**, 시간표 줄이 **목록**(점)으로 선다
6. **읽기 화면에서 고치기** — 복제한 둘째 벌을 **읽기 화면**으로 열어 둔 채 ··· → **줄바꿈 고치기** → 아래 띠 *… 2667개를 고쳤습니다.* (되돌리기 말은 없다) · 읽기 화면이 다시 그려지며 제목 · 목록이 선다 · 쓰기 화면으로 바꾸지 않아도 된다
7. 앱에서 새로 만든 아무 노트 · ··· → **줄바꿈 고치기가 없다** (고칠 글자가 없는 노트)
8. 지도 앱(네이버지도 또는 카카오맵)에서 장소를 공유 → 복사 → 노트에 붙여넣기 → 예전처럼 *[장소 이름](주소) : 길 주소* 한 줄 (같은 줄바꿈 목록을 쓰게 바꿨다)

**참고사항 (번호 없음)** — 앱을 껐다 켜도 고친 노트가 그대로 · 다른 앱에서 열어도 제목 · 목록이 선다 (파일이 고쳐졌다).
