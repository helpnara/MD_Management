# 안정화 시험 목록 (T3)

**언제 쓰나.** 스토어에 올리기 전 · 큰 변경 뒤 · S8(크래시 0건 2주)을 시작할 때.
한 번에 다 하지 않아도 된다. **칸마다 무엇을 지키는지 적어 두었으니**, 거슬리는 자리가
생기면 그 칸부터 본다.

**왜 목록이 필요한가.** 지금까지 잡힌 것 가운데 **되튐**(고친 것이 다른 것을 깨뜨림)이
여럿이었다 — 100 → 105, 107 → 110, 110 → 115. 되튐은 **그 기능을 안 건드렸을 때** 생기므로,
건드린 자리만 보면 놓친다.

> **적는 법.** `docs/08-feedback.md` 에 번호로 쌓는다. 여기 목록은 **고치지 않는다** —
> 새 칸이 필요하면 맨 아래에 더한다.

---

## A. 자료가 사라지지 않는가 — 가장 비싼 것부터

| # | 해 보는 일 | 지키는 것 |
|---|---|---|
| A1 | 긴 글을 치다가 **앱을 강제 종료** → 다시 켠다 | 마지막 글자까지 있다 (S2) |
| A2 | 치는 도중에 **노트를 바꿨다 돌아온다** | 끝까지 남아 있다 (94) |
| A3 | 치는 도중에 **비행기 모드** → 풀고 다른 기기를 켠다 | 두 글이 다 남는다. 진짜 충돌만 `(충돌 …)` (S4 · A15) |
| A4 | 두 기기를 켜 두고 **번갈아 길게** 고친다 | 헛충돌이 안 난다 (94) |
| A5 | 아직 안 내려온 노트를 **열자마자** 고친다 | 잘린 글이 저장되지 않는다 (86) |
| A6 | 폴더를 **옮기거나 이름을 바꾼 채** 앱을 켜 둔다 | 따라가거나 기본 폴더로 돌아오며 알린다 (84) |

## B. 앱이 본문을 함부로 고치지 않는가

| # | 해 보는 일 | 지키는 것 |
|---|---|---|
| B1 | 다른 앱에서 만든 **머리말 있는 노트**를 연다 | 본문이 한 글자도 안 바뀐다 (107) |
| B2 | **이름과 첫 줄이 다른 노트**를 연다 | 그대로 둔다 (107) |
| B3 | 첫 줄 제목을 **천천히** 친다 | 치는 도중에 글이 뒤집히지 않는다 (103) |
| B4 | 사진 든 노트를 옮기고 **`그냥 옮기기`** | 본문이 한 글자도 안 바뀐다 (114) |
| B5 | `#태그` 가 든 노트를 **다른 앱에서 연다** | 그냥 `#회의` 다 — 아무것도 안 더했다 (113) |

> **앱이 본문을 고치는 자리는 하나뿐이다** — 옮길 때 링크 고치기(114), 그것도 물어본 뒤에.
> 이 칸이 깨지면 ADR-0001 이 깨진 것이다.

## C. 편집기 — 한글과 커서

| # | 해 보는 일 | 지키는 것 |
|---|---|---|
| C1 | 한글을 **빠르게** 친다 | 조합이 안 끊긴다 (S10) |
| C2 | 300줄 노트에서 커서를 **위아래로 훑는다** | 지연 · 튐이 없다 (S11) |
| C3 | 기호 붙은 줄을 **탭한다** | 바로 회색으로 보이고 화면이 안 끌려간다 (100 · 105) |
| C4 | `⌘Z` 를 여러 번 | 낱말 단위로 물러난다 (S10 · 53) |
| C5 | 목록에서 **탭 · 시프트 탭** | 네 단계까지 들어가고 나온다 (91 · 112) |
| C6 | 번호 목록 가운데를 **지운다** | 아래가 1 · 2 · 3 으로 맞춰진다 (104) |
| C7 | 위가 `6.` 인데 **`5.` 을 친다** | 그대로 `5.` 다 (106) |

## 마지막 칸 — S8

**크래시 0건 2주.** 앱이 죽으면 **설정 → 개인정보 보호 → 분석 데이터**의 크래시 로그부터
받는다 (CLAUDE.md §3-5). 죽지 않은 2주가 지나야 안정화 표가 다 찬다.
