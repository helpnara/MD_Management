## 빌드 109 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1.9 (109)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터

**붙여넣기**

1. 네이버 지도 앱에서 장소 하나 → **공유 → 복사**(클립보드 복사) → 이 앱에서 노트를 쓰는 화면으로 열고 빈 줄에 **붙여넣기** →
   `[장소 이름](<https://naver.me/…>) : 주소` **한 줄**이 들어가고, 화면 아래 띠에 *지도 장소를 링크로 만들었습니다* 가 뜬다
2. 카카오맵 앱에서 장소 하나 → 공유 → 복사 → 붙여넣기 → `[장소 이름](<https://kko.to/…>)` 한 줄 (주소 없이 이름만)
3. 확인 목록에 적은 **네이버지도 두 곳 예시 글**을 통째로 복사해 붙여넣기 → 두 줄이 **사이에 빈 줄 하나**를 두고 들어간다
4. 3 바로 뒤에 **되돌리기**(세 손가락으로 왼쪽으로 쓸기 · 또는 아이폰 흔들기 → 실행 취소) → 원래 공유 글(`[네이버지도]` 네 줄씩)로 돌아간다
5. 읽기로 넘긴다 → 장소마다 **한 줄씩** 파란 링크(장소 이름) 뒤에 `: 주소` → 링크를 누르면 지도 쪽(앱 또는 사파리)이 열린다
6. 공유 글 **앞에 다른 글을 한 줄 더해** 복사한 뒤 붙여넣기(예: `오늘 갈 곳` 다음 줄에 카카오맵 글) → 바꾸지 않고 **복사한 글 그대로** 들어간다 (띠 없음)

**공유 창**

7. 네이버 지도 앱에서 장소 → **공유 → 느린 여백** → 넣을 곳 **새 노트** → 저장 → 이 앱을 열면 `받은 글` 폴더에 **장소 이름이 제목인 노트**가 있고,
   열면 맨 위 제목 줄 아래에 1 과 같은 링크 한 줄이 있다
8. 카카오맵 앱에서 장소 → 공유 → 느린 여백 → 넣을 곳에서 **고정한 노트** 하나 → 그 노트 맨 끝에 `- [장소 이름](<https://kko.to/…>)` 목록 한 줄이 붙어 있다

**7 · 8 에서 링크 한 줄이 아니라 주소만 붙거나 공유 줄에 느린 여백이 없으면** 그대로 알려 주세요 — 지도 앱이 공유 창에 무엇을 싣는지는
여기서 볼 수 없어서(글 대신 주소만 실을 수 있다) 실기기에서 처음 본다.

**참고사항 (번호 없음)** — 새 아이콘(251)은 그대로다. 다른 앱에서 열어도 링크 줄이 같은 모양이다.
