**가장 모르는 것.** `Files` 의 겉이름이 언어별 문구 파일로 바뀌는지는 여기서 확인할 수 없다 — 여러 단계 안쪽 값이다. 이름은 **아이폰 전체 언어**를 따를 것이고(공유 메뉴와 같은 까닭),
iCloud 가 이름을 오래 붙들고 있어 **바로 안 바뀔 수 있다.** 바뀌지 않아도 자료에는 영향이 없다 — 그때는 겉이름을 하나로 정하는 길을 다시 묻는다.
