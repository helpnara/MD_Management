**가장 모르는 것.** `Files` 의 겉이름이 언어별 문구 파일로 바뀌는지는 여기서 확인할 수 없다 — 여러 단계 안쪽 값이다. 이름은 **아이폰 전체 언어**를 따를 것이고(공유 메뉴와 같은 까닭),
iCloud 가 이름을 오래 붙들고 있어 **바로 안 바뀔 수 있다.** 바뀌지 않아도 자료에는 영향이 없다 — 그때는 겉이름을 하나로 정하는 길을 다시 묻는다.

## 빌드 90 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

0. 설정 → 진단 정보 → **판** 이 `1.1 (90)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터

**한국어 그대로인가**

1. 폴더 화면 맨 위 줄이 `느린 여백` · 설정 → **폴더 이름** 이 `느린 여백`
2. 폴더 하나를 길게 → **다른 폴더로 옮기기** → 목록 첫 줄이 `느린 여백 (맨 위)` (취소)

**이 앱만 English** (설정 앱 → 느린 여백 → 언어 → English)

3. 폴더 화면 맨 위 줄이 `Slow Margin` · Settings → **Folder Name** 이 `Slow Margin`
4. 폴더 하나를 길게 → **Move to Another Folder** → 목록 첫 줄이 `Slow Margin (Top Level)` (Cancel)
5. **파일** 앱 → iCloud Drive → 폴더는 `느린 여백` **하나뿐**이다 (아이폰 전체는 한국어라 겉이름은 그대로 — 폴더가 둘로 갈리지 않았나를 본다)

**아이폰 전체를 English 로 (겉이름이 먹히나 — 가장 모르는 것)** — 설정 → 일반 → 언어 및 지역 → English

6. **파일** 앱 → iCloud Drive → 폴더 이름이 `Slow Margin` 이고 **그 하나뿐**이다 (`느린 여백` 이 따로 남지 않는다) · 안의 노트 · 폴더가 그대로.
   바로 안 바뀌면 앱을 한 번 열었다 닫고 몇 분 뒤 다시 본다. **끝내 안 바뀌어도 실패가 아니다** — 그대로인지 알려 주면 된다 (자료는 같은 폴더다)
7. 홈 화면 아이콘 이름 · 사파리 공유 메뉴의 이름이 `Slow Margin`
8. 앱을 열어 **New Note** 를 하나 만든다 → 파일 앱의 그 폴더에 `New Note.md` 가 보인다
9. 아이폰 언어를 한국어로 되돌린다 → 파일 앱 폴더 이름이 `느린 여백` 으로 돌아오고 (늦을 수 있다) 8 의 `New Note.md` 가 그 안에 있다
