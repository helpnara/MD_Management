## 빌드 134 확인 목록 — 사용자 관점 (코드를 읽고 적었다 · 286 절의 경우의 수 표가 바탕)

0. 설정 → 진단 정보 → **판** 이 `1.1.19 (134)` — 아니면 테스트플라이트에서 업데이트한 뒤 1 부터

**아이폰**

1. 아무 노트를 열어 **쓰기 모드**에서 한 글자를 더 쓴 뒤 → 오른쪽 위 **···** → *살펴보기* 의 **모든 노트에서 찾기** → 시트가 뜨고 **자판이 바로 올라오며** 빈 칸 아래 *최근 고친 노트* 가 보인다
2. 그 칸에 **다른 노트에만 있는 낱말** 두 글자 → 결과 → 한 줄을 누른다 → 시트가 닫히고 **목록을 거치지 않고** 그 노트가 열린다 → 뒤로 가서 1 의 노트를 열면 더 쓴 글자가 **저장돼 있다**
3. 노트를 연 채 다시 ··· → 모든 노트에서 찾기 → 두 글자를 치고 → **닫기** → 노트가 그대로다 → 뒤로 가 노트 목록 · 폴더 화면에 가도 찾기 칸이 **비어 있고** 결과 화면이 아니다

**아이패드 (가로 · 세 칸)**

4. 폴더 칸을 **끝까지 민다** (폴더가 화면보다 적으면 시험 도구의 규모 시험 폴더로 채운다) → 찾기 칸이 **맨 위에 그대로 남는다** · 띠의 바탕이 칸의 바탕과 어긋나 보이지 않는다 (어긋나면 화면을 보내 주세요 — 색을 맞춘다)
5. 노트 목록 칸 위의 **칸 단추**(왼쪽 위 네모)로 폴더 칸을 접는다 → 노트 목록 막대에 **돋보기**가 생긴다 → 누르면 시트 · 자판 → 결과를 고르면 시트가 닫히고 **두 칸 그대로** 그 노트가 오른쪽에
6. 폴더 칸을 다시 펼친다 → 돋보기가 **사라진다** (폴더 칸의 칸이 그 몫)
7. 폴더 칸 · 노트 목록을 다 접어 **노트만 크게** → ··· → 모든 노트에서 찾기 → 고르면 **노트만 바뀌고** 칸이 열리지 않는다
8. **외장 키보드** — 세 칸에서 **⌘F** → 폴더 칸의 찾기 칸에 커서 (시트가 아니다) · 폴더 칸을 접고 ⌘F → **시트** · 시트에서 **esc** → 닫힌다 · 설정을 연 채 ⌘F → 아무 일도 없다
9. 아이패드를 **세로**로 돌려 폴더 칸이 숨은 상태에서 ⌘F (또는 ···) → 시트 → 고르면 가로로 돌리지 않아도 노트가 바뀐다
10. 시트에서 **한 글자**만 → 최근 고친 노트 그대로 · **없는 말** 두 글자 → *결과 없음* 화면 · 아직 안 받은 노트를 고르면 받으면서 열린다 (iCloud 에 내린 노트가 있으면)

**참고사항 (번호 없음)** — 앱을 껐다 켜도 노트 · 고정 · 찾기가 그대로 · 다른 앱에서 열어도 파일이 같다.
