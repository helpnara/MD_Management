## 빌드 67 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

**번호 목록 (192)** — 제목 줄(첫 줄) **아래**에서 한다. 목록이 노트 맨 첫 줄이면 첫 항목을 다 지운 빈 줄 위에 지울 줄이 없다.

1. 새 노트의 제목 줄 아래에 `1. 하나` 를 치고 엔터 → `둘` → 엔터 → `셋` → `1. 하나 · 2. 둘 · 3. 셋` 이 된다
2. `하나` 끝에 커서를 두고 **지우기를 계속 눌러** 첫 줄을 빈 줄로 만들고, **한 번 더** 눌러 빈 줄도 지운다 → 남은 두 줄이 `1. 둘 · 2. 셋` 으로 바뀐다
3. 다시 `1. 가 · 2. 나 · 3. 다` 를 만들고 **가운데 `2. 나`** 줄을 같은 방법으로 지운다 → `1. 가 · 2. 다`
4. `1. 가` 의 숫자 `1` 을 지우고 `5` 를 친다 → `5. 가` 로 남고, 아래 번호는 **저절로 바뀌지 않는다** (손으로 친 번호는 그대로 — 예전과 같다)

**목록 모양 단추 (193)** — 도구 띠의 **들여쓰기 · 내어쓰기 바로 앞** 목록 아이콘

5. `1. 가나다` 를 치고 엔터 → 들여쓰기 → 줄이 `1.` 로 한 단계 들어간다 → **목록 단추를 한 번** 누른다 → `-` 글머리표로 바뀌고, 이어서 `하위` 를 치면 `가나다` 밑의 글머리표 항목이 된다
6. 그 줄에서 목록 단추를 **한 번 더** → 다시 번호(`1.`)로 돌아온다
7. 목록 단추를 **길게** 누른다 → 글머리표 · 번호 · 체크상자 · 목록 해제 메뉴가 뜬다 → **체크상자** → 그 줄이 체크상자가 된다
8. 글머리표 `- 장보기` 줄에서 길게 눌러 **목록 해제** → `장보기` 만 남는다
9. **빈 줄**에서 목록 단추 → `- ` 가 들어가고 커서가 그 뒤에 선다
10. 글머리표 세 줄을 **함께 골라** 목록 단추 → `1. · 2. · 3.` 으로 바뀐다
11. 5 ~ 10 을 하는 동안 **키보드가 내려가지 않는다**
12. 읽기 모드로 바꿔 5 의 결과를 본다 → `1. 가나다` 밑에 `하위` 가 **한 단계 들어간** 글머리표로 보인다

## 빌드 68 확인 목록 — 사용자 관점 (코드를 읽고 적었다)

**번호 (195)** — 제목 줄 **아래**에서.

1. `1. 가 · 2. 나 · 3. 다` 를 만들고 `1` 을 지운 뒤 `5` 를 친다 → **치자마자** 아래가 `6. 나 · 7. 다` 가 된다
2. 이어서 `7. 다` 끝에서 엔터 → 새 줄이 `8.` 이고, 위의 5 · 6 · 7 은 그대로다
3. `5` 를 지우고 `1` 을 친다 → 아래가 다시 `2 · 3 · 4` 가 된다
4. 가운데 `2.` 의 숫자를 지우고 `9` 를 친다 → `9.` 로 남고 다른 번호는 안 바뀐다. **그 뒤 엔터나 들여쓰기를 하면** `9` 는 제 차례 번호로
   돌아간다 (읽기 화면은 처음부터 제 차례 번호로 보여 준다 — 가운데 번호는 마크다운이 안 본다)

**목록 단추 (194 · 195)**

5. `- 장보기` 줄에서 목록 단추를 **길게** 눌러 **목록 해제** → `장보기` 만 남는다
6. `1. 가 · 2. 나 · 3. 다` 의 **`1. 가` 줄**에서 길게 눌러 **목록 해제** → `가` 만 남고 아래가 `1. 나 · 2. 다` 가 된다

8. 다시 `1. 가 · 2. 나 · 3. 다` 를 만들고 **`1. 가` 줄**에서 목록 단추를 **한 번** → `- 가` 가 되고 아래가 `1. 나 · 2. 다` 가 된다
